# v0.5 통합 보고

브랜치 `v0.5`(규칙 `wip/v05-sim` 위에 화면·그림·소리를 `--no-ff`로 합쳤다). main에는 합치지 않았다. 기획 기준: `docs/DESIGN_v0.5.md`.

## 1. 무엇이 들어갔나
- **규칙**: 끝 목표 없음 + 민력·연표 + 장부의 마지막 장, 먹을 것 순서(판자 토끼버거 / 성채 완탕면), 새는 돈, 창고 세 크기, 불·병 밀도, 아래층 어둠, 조직(층 규칙·치안·갈등·부랑자·선금), 쉬었음시민, 물·받침·빈 칸.
- **화면**: 먹빛 계기 + 종이 창(시안 '다'), 글꼴 Hahmlet·Noto Sans KR. 이번 통합에서 더한 것: 위 띠 민력 날짜, 네모청 연표 탭, 연표 새 줄 쪽지, 장부의 마지막 장 종이 창(+네모청 '마지막 장' 탭), 장부의 치안·갈등 막대와 쉬었음시민·새는 돈 줄, 첫 불·첫 병 카드, 창고 렌즈, 안내 문구 갱신, 살피기 창의 덮인 층·옆의 조직.
- **그림**: 간판 한자 섞기, 덮인 아래층 어둡게(이제 규칙의 `covered_depth`를 한 번에 받는다 — `render.json cover.source = sim`), 고요시간 주민 정지·화면 어둡게.
- **소리**: Kenney UI 효과음, 곡 6, 확대에 따른 음악↔생활 소리, 고요시간(음악 사라지고 배관·발소리). 출처 확인이 약한 C 등급 세 줄(비·망치·발소리)과 파일은 통합에서 지웠다(합성으로 돌아감, CREDITS에서도 뺐다).

## 4. 각 층이 정한 것 — 승인이 필요하다 (번호는 `ASSUMPTIONS_AND_EXPERIMENTS.md`의 A37~와 같다)
37. [규칙 SIM] 연표·마지막 장 기준 날짜: 민력 17년 겨울 = 게임 41.25일째(사흘 = 한 해, 계절 넷 = 0.75일씩). 첫 계절만 '장마', 그 뒤는 봄·여름·가을·겨울.
38. [SIM] 고요시간은 03:12 시작, 03:30 끝('조금 뒤'의 값이 없어서).
39. [SIM] 치안 = 가동 중인 조직 시설 수 × 15(최대 100), 30 미만이 낮음. 조직이 없으면 치안 0이라 주민 40명 이상이면 조직 없이도 부랑자 사건이 가끔(하루 0.25번꼴) 난다. 사건은 약하다(좌판 하루 쉼 / 금고 1%(20~300달러) / 작은 불).
40. [SIM] 갈등: 두 조직이 다 가동 중이면 하루 4 + 3 × |시설 수 차이|만큼 쌓이고, 사이 층의 중립 시설(네모청·글방·사당) 하나마다 하루 2씩 식는다. 가득(100)이면 조직 시설 하나에서 불(50%)이나 파손(하루 정지)이 나고 0으로 돌아간다.
41. [SIM] 시민 영향의 '범위' = 조직 시설과 같은 층 가로·세로 4칸, 가동 중인 시설만. 십삼요회 옆 승급 공사 ×1.5, 연우당 옆 병 가중치 ×2.
42. [SIM] 선금 ×1.5는 건설비의 돈에만 얹었다(자재는 그대로). 철거 환불이 없으니 선금은 사라지는 값이다.
43. [SIM] 새는 돈: 기준 = 3,000 + 인구 × 150달러, 넘는 몫의 하루 3%, 치안 100이면 60% 덜 샌다. 시작 금고(1,200)는 닿지 않는다.
44. [SIM] 창고: 칸당 한도 소비재·원료 150, 건축자재 100. 작은 창고 50달러, 큰 창고 400달러+고물 20. 해금 단계 t1_20·t1_20·t2_40. 덮이지 않은 층 −15%는 작은 창고가 열린 뒤부터. 창고는 완공이면 덮는다.
45. [SIM] 불·병 밀도: 불 위험 상한 = 0.06 + 0.5 × (층 쓰인 칸/256) + 0.08 × 덮인 층 수, 병은 오물 속도 배수 = 0.4 + 1.0 × 칸 비율 + 0.12 × 덮인 층 수. 시작 뒤 유예 2일.
46. [SIM] 불밥통은 t1_20, 밤배꾼·봉합방은 t2_1에서 연다(층 해금에서 떼면서 정함). 층 해금 단계 floor2·floor3는 빈 단계로 남는다.
47. [SIM] 받침 값의 기준: 시설 = 건설비(돈), 주거 = 계층별 수리비 표(30·120·500·1500·3000).
48. [SIM] 먹을 것: 토끼버거 취급 시장 등급 3→2, 완탕면 2→3. 토끼버거 노점 일손을 판자시민 4명으로. 완자 공방·구룡완탕은 t3_1, 토끼집·토끼버거는 t2_1에서 연다.
49. [SIM] 쉬었음시민 = 벽틈시민(주민+대기) − floor(그 × 0.75). 소일: 행복 +0.05/명(최대 +2), 오물 −0.2%/명·병 확률 −0.2%/명(각 최대 −20%).
