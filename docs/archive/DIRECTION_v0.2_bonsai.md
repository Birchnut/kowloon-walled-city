# 구룡성채 — 디렉터 방향서 (v0.2, 2026-11-10)

> 이 문서는 **디렉터(Claude)가 내린 판단**이다. Jin이 직접 고른 것은 `DECISIONS.md`, 내가 정한 것은 여기.
> 충돌하면: Jin의 최신 발언 > 이 문서 > GDD.md(v0.1 초안, 일부 낡음).
> 모든 항목 끝의 `↩` 는 "뒤집는 비용". MVP를 보고 뜯어고치는 걸 전제로 쓴다.

## 0. 한 문장

**도시를 짓지 않는다. 기른다.** — 구룡성채 분재(盆栽).
대장은 방을 놓지 않는다. *이유*(일터·허가·빈터)를 놓고, 사람들이 *결과*(방·간판·빨래)를 쌓는다.
한 달 뒤의 실루엣은 내가 내린 결정의 화석이다.

## 1. 기둥 4개 (모든 기능은 이 중 하나를 섬겨야 한다)

1. **자란다** — 접속할 때마다 어제와 다른 덩어리. 성장은 보이는 사건이다(대나무 비계 → 방 → 불 켜짐).
2. **내 탓이다** — 모든 외형은 원인이 있다. "왜 여기가 이렇게 생겼지?"에 항상 답이 있다(허가했으니까, 안 거뒀으니까, 비워뒀으니까).
3. **들여다본다** — 멀리서는 기괴한 덩어리, 돌려보고 층을 열면 국숫집 아주머니. 관찰 자체가 보상.
4. **대가가 있다** — 좋은 선택/나쁜 선택이 아니라 다른 대가. 돈은 쉽게 벌수록 주도권을 가져간다.

## 2. 디렉터 콜 (D) — 내가 정했고, 이유는 이렇다

### D1. 2D 아이소 스프라이트를 버리고 **"3D 픽셀"**로 간다
3D 씬(직교 카메라)을 저해상도로 렌더링해 정수배 확대 → 화면은 픽셀아트, 구조는 3D.
- 네가 말한 **4방향 회전, 층 버튼으로 천장 열기, 안에서 걷는 사람**이 2D에선 각각 별도 대공사(스프라이트 4벌, 정렬 지옥)인데 3D에선 카메라 회전·층 숨기기·그냥 걷기다. "최종 버전의 꿈"이 아니라 **MVP 기본기**가 된다. 자유 회전·1인칭 걷기도 같은 구조 위에서 열림.
- 간판을 **데이터의 글자**로 만든다(魚蛋, 牙科, 마작). 업종이 늘면 간판이 저절로 는다.
- 낮/밤이 팔레트 틴트가 아니라 **실제 광원**(창문 불빛, 네온 번짐).
- 리스크(솔직히): 손으로 찍은 픽셀아트의 장인 맛은 안 난다. 대신 "절차적으로 일관된 픽셀 룩"(A Short Hike·Townscaper 계열). 열화판이 아니라 다른 스타일이다. 저사양 폰 웹에서의 성능은 검증 필요.
- 어제의 "코드로 모듈 타일 생성 + CC0 데칼" 결정은 그대로 산다(모듈 = 절차 메시+절차 텍스처, CC0 스프라이트 = 빌보드/벽면 데칼).
- ↩ 뷰 레이어만 교체. 시뮬·UI는 무관(ARCHITECTURE.md 참고).

### D2. 플레이어의 동사는 5개: **심기 · 긋기 · 허가 · 거두기 · 결재**
어제 너는 "정책만 정하고 자동 성장"을 골랐고, 오늘은 "구획·허가·작업장 설치엔 관여"라고 했다. 둘을 합치면 분재다.
| 동사 | 하는 일 | 화분 비유 |
|---|---|---|
| 심기 | 공공 시설·일터(앵커)를 **한 칸** 직접 놓는다. 텃밭, 고물 작업대, 공동수도, 발전기, 사당… | 씨앗 |
| 긋기 | 기둥(바닥 칸)에 주거/일터/**비움** 을 칠한다. 철거·보존도 여기 | 가지치기·철사 걸기 |
| 허가 | 농업/제조/오락/음성 × 금지·허가·장려, 입주·돌봄·세금·자재·경관 | 화분 방향·흙 |
| 거두기 | 수금함에 쌓인 돈을 탭해 거둔다 | 물 주기 |
| 결재 | 하루 끝에 올라온 제안 카드 3장 | 진단 |
- **방은 절대 직접 놓지 않는다.** 앵커 주변에 사람들이 알아서 붙는다. 이게 "유기적"의 정체.
- ↩ 동사 하나 = 명령 하나 + UI 버튼 하나. 빼고 넣기 쉬움.

### D3. "방치 시 부패"는 썩는 게 아니라 **부패(腐敗)** 다
그레이프밸리식 "안 거두면 시든다"는 2012년 문법이다. 죄책감으로 접속시키는 게임은 며칠 쉬면 그만둔다.
- 안 거둔 돈은 사라지지 않는다. **수금원이 떼먹는다.** 떼인 돈은 "뒷골목 금고"에 쌓이고 → 악명↑ → 일수·하우스 같은 음성 사업 제안이 올라온다.
- 즉 **자리를 비우면 도시는 벌 받지 않고 표류한다.** 깨끗한 성채는 성실함의 결과, 음성 성채는 방임(혹은 의도적 방임)의 결과. 구룡성채의 본질("공식 제도가 비면 사람들이 자기 규칙을 만든다")과 정확히 같은 구조.
- ↩ `collection` 시스템 하나. 스킴 비율 0이면 순수 방치형.

### D4. 수금함은 앵커에 달린다 → **세금이 공간이 된다**
앵커를 심으면 그 주변이 "수금 구역"이 된다. 구역 밖에 자란 방은 세금을 안 낸다(비공식 구역).
어디에 심느냐가 곧 어디까지 내 통치가 닿느냐. 말풍선 수도 앵커 수로 자연히 제한된다.
- ↩ 반경 값 하나.

### D5. 도시 타입은 없다. **명물(名物)** 이 있다
사이버펑크/목가는 예시일 뿐이라는 네 말에 동의. 템플릿을 두지 않는다.
- 업종·자재·시설이 임계량을 넘으면 태그가 붙고("어묵", "무면허 치과", "비둘기", "함석", "사당"…), 상위 태그 조합으로 **별명이 자동 생성**된다: "어묵 냄새 나는 함석 미궁", "천 개의 치과", "비둘기와 마작의 옥상".
- 호칭(대장→촌장/따거/회장…)도 같은 태그에서 나온다.
- 실제 구룡성채 고증이 씨앗: 어묵 공장, 무면허 치과, 제면소, 쪽방(籠屋), 옥상 비둘기장, 대나무 비계, **머리 위를 스치는 비행기**(카이탁).
- 내가 기대하는 비(非)템플릿 성채들: 물탱크와 양어 수조의 **수상 성채** / 향 연기와 장례업의 **사당 성채** / 버섯방과 약초방의 **어둠 농업 성채**(빛이 없는 게 자원) / 전파사와 해적방송의 **안테나 숲** / 목욕탕 굴뚝과 발전기 폐열의 **온수 성채**.
- ↩ `identity` 시스템 + 데이터 태그. 완전 제거해도 게임은 돈다.

### D6. 자원은 3재고 + 2용량 + 3지표
돈·식량·자재 / 물·전기(인구·업종 상한) / 위신·악명·민심. 이 이상은 MVP에서 안 늘린다.
- ↩ 데이터.

### D7. 합격 기준은 "봇 3명의 30일 타임랩스가 서로 다르게 생겼는가"
성향이 다른 자동 플레이어 3종(성실한 농부 / 방임하는 장사꾼 / 공장주)을 30일 돌려 실루엣을 나란히 뽑는다. 셋이 비슷하면 시뮬이 실패한 것. 숫자는 여기에 맞춰 튠한다(네 원칙: 숫자는 시뮬로).

### D8. 입주·돌봄 정책은 두 축으로 쪼갠다
네가 한 묶음으로 말한 "누구나/노동우선/추방/공동부조"는 서로 배타적이지 않다(누구나 받으면서 공동부조도 할 수 있다).
→ **입주**(누구나 / 여력만큼 / 일꾼 우선) × **돌봄**(각자도생 / 공동부조 / 추방).
- ↩ policies.json.

## 3. 챌린지 (C) — 네 생각에 내가 거는 반론

- **C1. "유기적 관여"와 "자율 성장"을 둘 다 원하면 보통 어중간해진다.** 내 답이 D2다: 플레이어는 원인만, 도시는 결과만. 이 선이 흐려지면(방도 직접 놓게 해달라 등) 심시티가 되고 "화분"이 죽는다. MVP에서 답답하면 그때 선을 옮기자.
- **C2. 12×12×8 상자 쌓기만으로는 모뉴먼트 밸리의 조형미가 안 나온다.** 실루엣은 예외에서 나온다: 반 칸 돌출, 건물 사이 다리, 외벽 계단, 옥탑, 굴뚝. 이것들은 시뮬 규칙이 아니라 **뷰가 셀 배치에서 절차적으로 파생**시킨다(시뮬은 단순, 겉은 복잡).
- **C3. 범죄 직설 풍자는 유지한다. 다만 재미는 묘사가 아니라 "주도권을 뺏기는 과정"에 둔다.** 콜센터가 들어오면 돈이 쏟아지고, 3개가 넘으면 '윗선'이 호칭을 정해준다. GTA의 통쾌함이 아니라 「대부」의 씁쓸함 쪽이 이 게임에 맞다고 본다.
- **C4. 한 달 실시간은 MVP에서 검증 불가다.** 그래서 시간 가속 + 봇 타임랩스(D7)를 개발 도구로 먼저 만든다. "한 달 뒤 모습"을 첫날 본다.
- **C5. 픽셀아트 '디테일 애니메이션'의 우선순위.** 전부 다는 못 한다. 상태를 알려주는 움직임만 먼저: 불 켜지는 창, 깜빡이는 네온, 김, 빨래, 걷는 사람, 비계. 장식용 애니는 뒤.

## 4. MVP(v0.2)에 들어가는 것 / 안 들어가는 것

**들어감**: 3D 픽셀 뷰(4방향 회전·줌·층 컷) / 낮밤 / 5동사 / 유입·성장·경제·수금(부패)·지표·카드·해금·명물 시스템(얇게) / 오프닝 / 저장·오프라인 요약 / 봇 타임랩스 도구
**안 들어감**: 가공 체인·등급, 인물 파견, 날씨, 소리, 통로 연결성 시뮬, 생체건축·컬트, 과금, 두 번째 부지

## 5. 아트 바이블 (요약)

- **깨끗한 덩어리, 지저분한 피부.** 큰 형태는 모뉴먼트 밸리처럼 단순한 상자와 절제된 팔레트(자재당 3톤). 잡동사니는 작고 채도 높게, 가장자리(발코니·간판·옥상)에만 몰아준다.
- 낮 = 뿌연 홍콩 아침의 따뜻한 파스텔. 밤 = 남보라 덩어리 + 따뜻한 창 + 포화된 네온.
- 성채는 진공에 떠 있지 않다: 그라디언트 하늘, 주변을 둘러싼 "합법 도시"의 먼 실루엣, 담장과 표석이 있는 잔해 부지.
- 시그니처 순간: ① 첫 전기의 밤(창이 차례로 켜짐) ② 비행기 그림자가 옥상을 훑고 지나감 ③ 대나무 비계가 걷히며 새 층이 드러남.
- 사람은 줌에 따라 2단계: 멀리선 3×7px 점사람, 가까이선 16×24 CC0 스프라이트.
