# 소리 노트 (브랜치 `aud4`, 2026-11-13)

구룡성채의 소리는 **전부 코드로 합성**한다. 음원 파일·내려받기 없음. 게임이 켜질 때 PCM 을 만들어 `AudioStreamWAV` 에 담고, 그다음은 보통 표본 재생만 한다(웹에서도 가장 안전한 길).
귀로 들어 보지 못했다 — 모든 확인은 숫자로 했다(아래 분석표). **사람 귀로 판단할 것은 §8.**

## 0. 한 번에 다시 보기

```
# 검사(모든 소리를 만들고 조용함/클리핑/NaN/직류·루프 이음매·만드는 시간·배경 논리·연타 막기·볼륨 API 확인, 표와 WAV 를 out 에)
godot --headless --path godot -s res://audio/audio_test.gd -- out=/tmp/kowloon_audio
#   → 마지막 줄 "AUDIO TEST: PASS", /tmp/kowloon_audio/report.md(아래 §4 표), *.wav(효과음 변주별, 루프는 두 번 이어 붙인 *_x2.wav)
# 미리 듣기: 편집기에서 res://audio/AudioSandbox.tscn 실행(F6). 효과음 = 단추 또는 1…0, Q…L 글쇠.
#   오른쪽 막대로 시각·인구·공사장·불·멀리 보기·배속·멈춤·비를 흉내 → 배경·음악이 따라간다. 버스 볼륨·음악·배경 켜고 끄기.
```

## 3. 크기 맞추기

1. 효과음·한 번짜리·악기: 만든 뒤 **귀 가중 짧은 RMS**(100 Hz 아래 2단 깎기 + 1.7 kHz 위 +4 dB 선반, 가장 시끄러운 50 ms)를 **-20 dBFS** 로 맞춘다. 봉우리가 -1 dBFS 를 넘으면 부드러운 무릎으로 누른다.
2. 들리는 차이는 재생 이득(`SfxBank.SPEC` 둘째 칸)으로만: 갈래별 목표(아래 '들리는 크기').
3. 루프는 RMS -22 dBFS(바탕 화음 -24), 층 기본 dB(`AudioDirector.LAYERS`) × 상태 크기.
4. 버스 기본: 주 0.9 · SFX 0.85 · 배경 0.7 · 음악 0.4(-8 dB). 주 버스에 HardLimiter(-0.5 dB) — 데스크톱용 안전망.

| 갈래 | 들리는 크기(귀 가중 짧은 RMS + 재생 이득) |
|---|---|
| hover | -37 |
| click · tab · rotate · speed · window | -27 … -28 |
| 칠하기·짓기·철거·승급·돈·해금 | -22 … -23 |
| 끝남 알림(공사·수리·계약·연구·탐험) | -23 … -26 |
| 목표·층·등급 | -19 … -20 |
| 경고(alert -25 · hazard_on -21 · fire -21 · disease -22 · fire_out -25) | |
| 배경 한 번짜리 | -32 … -40 (+ 무작위 -4…0, 배경 버스 -3) |

### 만드는 시간
메인 스레드 CPU(/proc, 10 ms 단위, 다른 작업과 2코어를 나눠 쓰는 상자): **효과음 ≈ 480 ms · 배경 한 번짜리 ≈ 260 · 악기 ≈ 30 · 루프+바탕 화음 ≈ 550 · 합 ≈ 1.3 s** (검사 기준 1.5 s, 효과음 0.6 s). 처음 만든 것은 4.1 s 였다 — 잔향을 반 표본율로, 낮은 소리·먼 소리·바탕을 11025 Hz 로, 부분음을 회전 페이저로 바꿔 줄였다.
게임에서는 **프레임마다 4 ms 씩** 나눠 만든다(`AudioDirector.BUDGET_MS`): 자주 쓰는 효과음 10개 → 바닥 루프 5개(배경이 1초 남짓에 시작) → 나머지 효과음 → 한 번짜리 → 악기 → 불·비 → 바탕 화음. 무거운 조리법(tier_up·goal·hazard_on…)은 중간에 프레임을 넘긴다. 헤드리스 부팅에서 다 만드는 데 155 프레임. 아직 안 만든 이름을 부르면 그 자리에서 만든다(한 번, 수 ms — 처음 몇 초에 무거운 것이 불리면 한 번 끊길 수 있다).

## 5. 배경이 도시를 따라가는 법

0.5초마다 읽는다(읽기만): `Game.view.tod()`(없으면 `Game.time_of_day()`), `Game.state.buildings` 한 번 훑어 **인구**(주거 residents 합), **공사장**(kind "site" 또는 build_left > 0), **불**(burn == "burning"; 그 칸이 없으면 사건 fire_started/fire_spread − fire_out 셈), `Game.view.zoom_i / _zoom_levels`(멀리 보기 0..1), `Game.speed`, `Game.paused`. `query("hud")` 는 쓰지 않는다(Metrics 계산이 무겁다).

시간 가중치(시각 h): 낮 = 5.5–7.5시에 오르고 17.5–19.5시에 내림 · 밤 = 4.5–6.5시까지, 19–21시부터 · 저녁 장 = 15.5–17시 오르고 19–20.5시 내림 · 아침 = 6–7.5 오르고 8.5–10 내림 · 깊은 밤 = 1–5시. 도시 크기 cs = 인구 / (인구 + 250).

| 층 | 목표 크기(0..1) |
|---|---|
| hum | (0.45 + 0.55·cs) × (1 − 0.25·깊은밤) |
| wind | 0.3 + 0.6·멀리 + 0.15·밤 |
| murmur | cs × 깨어있음 × (0.65 + 0.5·저녁 + 0.15·아침) × (0.8 + 0.35·가까이) |
| market | cs × (저녁 + 0.35·아침) × (0.75 + 0.35·가까이) |
| crickets | 밤 × (1 − 0.45·cs) |
| fire | 불 0 → 0, 아니면 min(1, 0.6 + 0.2·불 수) |
| rain | `Sfx.set_rain()` 값 |

크기는 2.5 s(불 1 s) 시간 상수로 천천히 따라가고, 2초 넘게 조용한 층은 멈췄다가 다시 필요하면 무작위 위치에서 시작한다. 시작은 4초 동안 서서히(웹은 첫 입력 뒤).

한 번짜리(분당, × 배속 기운 1 + 0.25·log2(배속) 최대 1.6, 멈춤이면 × 0.15, 서로 1.2 s 이상 띄움, 좌·가운데·우 무작위):
bird 5·낮·(1−0.4cs) · pigeon 1.5·(0.8낮+0.2저녁) · dog 0.7·(0.3+0.7cs)·(0.5+0.5밤) · bell 1.0·cs·min(1,낮+저녁)·0.9 · kettle 0.35·cs·(아침+저녁) · mahjong 1.2·cs·(0.6저녁+0.8밤)·(1−0.6깊은밤) · radio 0.5·cs·(저녁+0.6밤)·(1−0.7깊은밤) · hammer 3·min(공사장,3)/3·(0.4+0.6낮) · horn 0.25·(0.4+0.6밤) · drip 2·밤·(0.3+0.7cs) · wok 1.5·cs·(저녁+0.5아침+0.3낮) · shutter 0.4·cs·(아침+20.5–23시).

검사가 확인하는 모양(audio_test, 인구 600): 새벽 3시 = 웅웅 0.63·바람 0.75·웅성 0.09·귀뚜라미 0.68, 한 번짜리 2.7/분(물방울·개·마작) · 아침 8시 = 웅성 0.55·장 0.23, 8.2/분 · 낮 13시 멀리/가까이 = 바람 0.90/0.30, 웅성 0.37/0.53 · 저녁 18시 = 웅성 0.79·장 0.65, 7.8/분(×4 에서 11.7) · 밤 22시 불 2 = 불 층 1.0, 음악 alarm · 멈춤 = 0.5/분, 배경 버스 -9 dB, 음악 -5 dB.
배속은 **음높이를 바꾸지 않는다** — 한 번짜리 빈도만 조금 오른다.

음악: 실제 시간 기준(배속과 무관), 첫 구절은 시작 5초 뒤, 분위기가 바뀌면 바탕 화음을 4–5초에 걸쳐 교차, 불이 나면 1.5초 안에 alarm 구절.

## 6. 설정 창용 API (UI 통합 때)

```gdscript
Sfx.set_volume("master" | "sfx" | "ambience" | "music", 0.0..1.0)   # 0 이면 그 버스 끔. 바로 user://audio.cfg 에 저장
Sfx.get_volume(bus) -> float
Sfx.mute(true/false); Sfx.is_muted()            # 전체 끔(주 버스)
Sfx.muted = true/false                           # 효과음만 끔 — 지금 KeepWin 의 '효과음 끔' 단추 그대로 동작, 저장도 된다
Sfx.set_music_enabled(on); Sfx.music_enabled()
Sfx.set_ambience_enabled(on); Sfx.ambience_enabled()
Sfx.set_rain(0.0..1.0)                           # 뷰가 비를 그릴 때

```
`nosave`/`KOWLOON_NOSAVE=1` 실행은 audio.cfg 를 읽지도 쓰지도 않는다(UISettings 와 같은 규칙).

## 7. 내가 정한 것 (번호, 이유) — 승인 필요

A1. **시작할 때 미리 만들어 `AudioStreamWAV` 로 재생**, `AudioStreamGenerator` 는 안 씀 — 웹(스레드 없음·'표본 재생' 모드)에서 가장 안전하고, 실행 중 CPU 가 거의 0.
A2. **프레임 예산 4 ms 로 나눠 만들기 + 순서**(자주 쓰는 효과음 → 배경 바닥 → …). 웹에서 끊김을 피하려고. 대가: 전부 준비되기까지 데스크톱 2–3초, 웹은 더 걸릴 수 있다.
A3. **표본율 둘**: 밝은 효과음·악기 22050 Hz, 낮은/먼 소리·잡음 바닥·바탕 화음 11025 Hz. 만드는 값이 반. 웹·데스크톱 모두 Godot 가 다시 표본화한다.
A4. **크기 = 귀 가중 짧은 RMS -20 dBFS + 갈래별 재생 이득**(§3). LUFS 를 제대로 구현하는 대신 짧은 소리에 맞는 50 ms 창과 간단 가중을 썼다.
A5. **연타 막기**: 이름마다 간격(click 60 ms … tier_up 500 ms), 같은 이름 동시 3개, 효과음 목소리 12개(모자라면 가장 오래된 것을 끊음). 변주는 직전과 다른 것을 고르고 음높이를 ±2–4% 흔든다(큰 소리는 흔들지 않음).
A6. **이름 7개 추가**: tab, tier_up, construction_done, repair_done, contract_done, research_done, fire_out(hover 는 원래 있음). UI 가 부르지 않는 사건은 **Sfx 가 Game.event 를 듣고 스스로 낸다**(construction_done · research_done · contract_done(ok) · milestone→tier_up · fire_out · repaired/repair_done). 끄는 깃발 `auto_event_sfx`.
A7. **버스는 실행 중에 만든다**(SFX · Ambience · Music, 그리고 Ambience 로 보내는 AmbL/AmbR 좌우 패너). `default_bus_layout.tres` 는 만들지 않았다 — project 쪽 파일을 늘리지 않고, 다른 작업과 겹칠 일이 없게. 주 버스에 HardLimiter(-0.5 dB)를 한 번 단다(탐험 미니게임 소리도 같이 지나간다 — 봉우리만 막는 것이라 해는 없다고 봄).
A8. **`Sfx.muted` 는 '효과음만'**(지금 단추의 뜻 그대로), `Sfx.mute()` 는 전체. 설정은 `user://audio.cfg` 따로(ui_settings.cfg 와 섞지 않음).
A9. **상태는 Game.state 를 직접 훑는다**(0.5 s), query("hud") 대신 — hud 는 Metrics 전체 계산이라 무겁다. 뷰의 `zoom_i/_zoom_levels`(밑줄 붙은 멤버)도 읽는다(없으면 0.5).
A10. **빈 땅은 조용하다**: 인구 0 이면 웅웅·바람·새만. 사람 소리(웅성·장·마작·라디오·웍·자전거·주전자)는 인구 따라(cs) 자란다 — 성채가 자라는 게 귀로도 들리게.
A11. **밀집할수록 귀뚜라미·새가 줄어든다**(1 − 0.45·cs, 1 − 0.4·cs).
A12. **멈춤 = 배경 -9 dB · 음악 -5 dB · 한 번짜리 ×0.15**, 배속 = 한 번짜리 빈도만 최대 ×1.6. 음높이는 절대 안 바꿈.
A13. **음악 기본 켬, 볼륨 0.4**, 구절 사이가 길다(6–24 s). 불이 나면 alarm 분위기(긴장 음계 + 반음 맥놀이 바탕). 실제 시간 기준.
A14. **웹은 첫 입력(마우스·글쇠·터치) 뒤에 배경·음악 시작**, 데스크톱은 바로(4초 서서히).
A15. **의사 스테레오**: 루프는 오른쪽을 6–18 ms 늦춘 하스 효과(값이 거의 0), 한 번짜리는 AmbL/AmbR 버스로 좌우. 웹 '표본 재생'에서는 버스 효과가 빠지니 패너가 무시되고 가운데로 들린다(망가지지는 않음).
A16. **불 판단**: 건물에 `burn` 칸이 있으면(ARCHITECTURE v4) 그것만 믿고, 없으면 사건 셈. 사건만 믿으면 fire_out 을 놓쳤을 때 불 소리·alarm 음악이 영영 남을 수 있어서.
A17. **사람 목소리는 없다**(장사꾼 외침 등) — 알아들을 수 없는 웅성거림만. 합성 목소리는 우스꽝스러워지기 쉽다.
A18. **비 층은 만들어 두고 꺼 둠** — 뷰가 비를 그릴 때 `Sfx.set_rain()` 을 불러야 켜진다(지금 뷰 코드에 비 상태를 알려 주는 공개 값이 없다).
A19. **라디오 선율·음악 구절은 소리음계 + 씨앗**으로만 — 남의 곡을 닮을 일이 없게.

## 8. 귀가 없어서 확인 못 한 것 (사람이 들어 볼 것)

- **음색 전부**: '대나무 딱', '함석 쿵', '깡통 동전', '마작패'가 정말 그 재질로 들리는지. 숫자로는 길이·외피·무게중심만 맞췄다.
- **money**: 무게중심 2.85 kHz — 가장 밝은 효과음. 찰랑이 날카로우면 `SfxBank` money 의 `S.lp1(o, 6500.0)` 을 4500 쯤으로.
- **웅성거림(murmur)**이 사람 소리처럼 들리는지, 그냥 '보글거리는 잡음'인지. 가장 불확실한 층.
- **개(dog)·비둘기(pigeon)·주전자(kettle)** — 가장 '합성 티'가 날 것. 거슬리면 `AmbienceBank.SHOTS` 의 이득을 낮추거나 빈도표(`shot_rates`)에서 0 으로.
- **음악이 편안한지**, 오르골이 너무 맑거나 높지 않은지(낮 C5–C6). 바탕 화음(pad_tense 반음 맥놀이)이 불쾌하지 않은지.
- **섞인 크기**: 효과음 vs 배경 vs 음악의 상대 크기(§3 표는 숫자상 목표일 뿐). 특히 저녁 장터 + 웅성 + 웍이 겹칠 때.
- **루프 반복감**: 9–10초 루프가 몇 분 뒤 '돌고 있다'는 느낌을 주는지(층 길이가 서로 달라 전체 주기는 길다).
- **웹**: 첫 입력 뒤 소리 시작, '표본 재생' 모드에서 pitch_scale·루프·버스 볼륨이 데스크톱과 같은지, 만들기가 정말 안 끊기는지(브라우저를 열어 보지 못했다).
- 효과음 꼬리 10 ms 페이드·루프 이음매는 숫자로 통과했지만 아주 작은 딸깍이 남았을 수 있다.

## 9. 하지 않은 것 · 다음 생각

- 설정 창의 볼륨 막대 4개 + 음악/배경 켜기(§6 API 만 있음 — UI 통합 몫).
- UI 가 아직 `hover`(짓기 카드)와 `tab`(창 안 탭)을 부르지 않는다.
- 자리 있는 소리: 불난 집·공사장 쪽에서 들리게(AudioStreamPlayer2D/카메라 거리), 가까이 보면 그 시설의 소리(마작방·봉제방 재봉틀·완탕 김).
- 비·날씨 자동(뷰/시뮬에 비 상태가 생기면 `set_rain`).
- 병이 도는 동안의 바탕(기침·파리), outbreak_end 의 안도하는 소리, 단속(raid) 호루라기.
- 정식 LUFS 측정과 실제 섞인 소리의 크기 검사(지금은 소리 하나씩).
- 변주를 더(특히 build·zone·click 은 3개 + 음높이 흔들기뿐).
- 사람이 들을 수 있게 '대표 1분' 배경을 WAV 로 오프라인 렌더하는 도구.

## 10. 통합 때 부탁

- `project.godot`: **바꿀 것 없음**. (원하면 편집기에서 버스를 보이게 `default_bus_layout.tres` 를 만들 수 있다 — 실행 중 만드는 코드는 이미 있는 버스를 그대로 쓴다.)

- 뷰: 비를 그리면 `Sfx.set_rain(세기)`.
- 탐험 미니게임(`godot/expedition/`, 이 가지에는 없음)의 소리는 건드리지 않았다. 미니게임 소리도 주 버스 리미터를 지난다.
