# 가정과 실험 — 디렉터가 정했고, Jin이 뒤집을 수 있는 것

각 항목: 무엇을 / 왜 / 뒤집으면 바뀌는 곳. 숫자는 전부 `godot/data/`에 있다. 검증 결과는 `simulation/reports/`.

| # | 가정 | 왜 | 뒤집는 곳 |
|---|---|---|---|
| A1 | 주거 1칸 = 1단위. 칠하면 판잣집이 바로 선다 | 모바일에서 끌어서 칠하기가 가장 빠르다 | 건물 크기 데이터 |
| A2 | "쓰이는 칸"은 주민이 사는 주거 + 완공 시설만 | 빈 판잣집 도배로 층을 여는 것을 막는다 | config.floors |
| A3 | 지지대는 공짜 | 건축 자유가 먼저. 비용은 실험 후 | config.floors.support_cost |
| A4 | 세 계열 자재는 주거 승급(과 랜드마크)에만 쓴다. 시설은 돈+고물 | 자재 선택이 효율 문제가 아니라 외관 선택으로 남게 | buildings.json 비용 |
| A5 | 수요 역할 3개(기본/승급/여유). 승급 = 만실 + 승급 수요 충족 | 브리프 7장의 세 그룹을 화면에서 읽히게 | needs.json role |
| A6 | 계약은 경제 시계를 따른다 | 미접속 0.25배일 때 수입이 소비보다 4배 빨리 오면 재고가 어긋난다 | config.time |
| A7 | 정원이 주는 승급: 빈집으로 자동 이주 → 없으면 3경제일 대기 → 그래도 없으면 떠남 | 인구가 조용히 사라지지 않게, 그러나 승급을 막지도 않게 | upgrade_costs.relocation |
| A8 | 해금은 영구 | 인구가 줄었다고 지은 게 못 쓰게 되면 억울하다 | unlocks.json |
| A9 | 탐험대는 거점당 1팀, 최대 3 | 클릭 노동과 무한 증식 방지 | destinations/teams |
| A10 | 보급(끼니 10 → 수확 +25%)은 선택 | 생산이 탐험을 돕는 가장 쉬운 연결 | destinations.provision |
| A11 | 정책·연구 트리 추가 | Jin 요청. Anno 1800 본편에는 없음(DLC·다른 Anno) | policies/research.json |
| A12 | 단속 위험은 음성 시설만 건드린다(2일 폐쇄+벌금) | 권한을 빼앗지 않는 대가 | config.heat |
| A13 | 시작 재고에 세 자재 12씩 | 첫 승급을 탐험 기다림 없이 | config.start |
| A14 | 미접속: 0.25배속, 최대 8시간, 주민 이탈 없음 | Jin: 느리게 + 보호 | config.time.offline |
| A15 | 계층 세율 1.0/1.6/2.4/5.0/9.0 | 칸당 세수가 계층마다 오르게(4→54) | tiers.json |
