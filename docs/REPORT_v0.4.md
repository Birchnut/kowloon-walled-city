## 3. 내가 더한 것(자율 기획)

1. **성채식 조달**: 원재료를 수입하지 않는다. 주워 오고(수거단), 성채 안에서 2단계까지만 가공한다. 수입은 사치품(생선·원단 등)만, 전자 폐품·설비 부품은 탐험에서만.
2. **불과 병을 다르게**: 불은 짧고 급하다(범위 안이면 한 시간에 꺼지고, 밖이면 번진다). 병은 느리다(쓰레기가 며칠 쌓여야 돌고, 의원이 없으면 오래 앓는다).
3. **렌즈 8개**(수요·시장·놀 곳·소방·수거·의원·계층·행복): 범위와 빈 곳을 바닥 색으로 본다.
4. **던전 재고**: 털면 줄고 게임 시간으로 다시 찬다 — 같은 곳만 계속 털 수 없다. 자동 파견과 직접 줍기가 같은 재고를 쓴다.
5. **직접 줍기의 장치**: 배낭 6칸(무엇을 들고 나올지가 곧 도시 계획), 소란 게이지(오래 머물수록 들개 → 순찰 → 투광등 → 쥐 떼), 던지기 궤적, 맞으면 빙글 도는 슬랩스틱.
6. **봇 11종 × 씨앗 3개**로 속도를 맞췄다(§4). 직접 줍기는 자동 플레이어 3성격 × 200판.
7. **낮밤·날씨·네온**, 주민의 하루(출근·장보기·놀기·귀가), 5단계 확대.

## 4. 숫자(봇 시뮬레이션, 씨앗 3개 평균)

단위는 게임 날(×1에서 하루 = 실제 10분). 사람은 봇보다 두 배쯤 느리다고 본다.

| 이정표 | 균형형 봇 | 느긋한 봇(4시간마다 조금) |
|---|---|---|
| 첫 승급 | 1.2일 | 1.5일 |
| 2층(불 시작) | 5.5일 | 9.0일 |
| 박힌 돌(3계층) | 6.0일 | 9.5일 |
| 옥상 황제(5계층) | 16.9일 | 34.8일 |
| 마지막 목표(옥상 황제 80 + 무허가 구청) | **35.9일**(실제 약 6시간) | 48일 안에 못 함 |

- 자재 세 계열(목재·철제·콘크리트) 집중형의 끝나는 날 차이 1.9%.
- **방재를 무시하면**: 주거의 9.45%를 잃고(탄 건물 952, 떠난 주민 5,400), 수리비 ₩12만, 끝이 10% 늦다. 덮으면 손실 0.66%(작은 불·작은 병은 계속 난다).
- **직접 줍기**: 한 판 약 3분에 43개. 같은 게임 시간에 자동 파견의 2.3~3배. 직접 줍기를 섞은 봇이 1.4일 빨리 끝난다.
- 돈은 쌓이지 않는다(균형형 금고 = 세수 0.1~0.7일 치).
- 직접 줍기 한 판의 결과(보통 성격 200판): 두목 잡고 나옴 26% / 그냥 나옴 65% / 쓰러짐 10%, 가운데값 3.1분.
- 자세한 표: `simulation/reports/SUMMARY.md`, `simulation/reports/run_batch.md`.

**못 한 것(숨기지 않고)**
- 사람이 직접 해 보기 — 한 번도 없음. 특히 직접 줍기의 조작감, 글자 크기, 소리.
- 진짜 PC(그래픽카드)에서의 속도. 이 상자는 소프트웨어 렌더라 화면 속도를 믿을 수 없다. 규칙 계산은 집 1,800채에서 한 스텝 57ms(목표 25ms) — 후반 큰 도시에서 ×4가 버벅일 수 있다.
- 실제 브라우저(크롬·엣지·사파리) — 헤드리스 크로미움으로만 봤다. 웹에서 직접 줍기는 열어 보지 못했다.
- 나머지 목적지 6곳(철거 현장·폐공장·폐기물 처리장 등)의 고유 그림·적, 4~5계층 집 그림.
- 쓰레기 매립지는 봇으로 돌아가는 것만 봤고 조정하지 않았다.

  - 무허가 구청은 깡통 귀족 60 + 네온 용탑으로 열리고, 마지막 목표는 옥상 황제 80 + 구청.
  - 자동 파견 수확과 승급 자재를 같이 약 0.55배로 줄여 직접 줍기가 2~3배가 되게 했다.
  - 승급 비용 ₩40 / 300 / 2,000 / 4,000. 층은 아래층을 80% 채워야 열린다(이건 Jin이 예전에 정한 값 그대로).
- 그림: `docs/VIEW_NOTES.md` — 5단계 확대, 확대하면 지붕이 걷힘, 사람 크기, 간판 글꼴(갈무리).

## 7. Jin이 고를 것

해 본 뒤에 번호로 답해 주면 된다. 표시(*)는 지금 들어가 있는 값.

1. **직접 줍기의 방향** — 1) 지금처럼 피하기·한 대씩 치기* 2) 더 슈터답게(새총·못총, 적 더 많이) 3) 싸움을 줄이고 잠입·선택 위주
2. **한 판 길이** — 1) 3분* 2) 5분(방 9~10개) 3) 2분짜리 짧은 판 여러 번
3. **쓰러졌을 때** — 1) 절반 잃음* 2) 전부 잃음 3) 물건은 지키고 줍는 이만 다침(게임 시간으로 회복)
4. **자동 파견** — 1) 남긴다(직접의 1/2~1/3)* 2) 없앤다(탐험은 전부 직접) 3) 연구로 나중에 열리는 편의 기능으로
5. **교역 없이도 끝까지 갈 수 있어야 하나** — 1) 아니다, 사치품은 수입* 2) 그렇다(스시 재료 등을 성채 안에서도 만들 길을 연다)
6. **간판** — 1) 전부 한글* 2) 간판에만 한자 섞기(홍콩 분위기) 3) 한글 + 영어
7. **이름의 결**(`docs/GDD_PC.md` §8 목록을 보고) — 1) 이대로* 2) 더 세게(더 어이없게) 3) 덜 장난스럽게 4) 마음에 안 드는 것만 짚어 주기
8. **방재를 무시한 대가** — 1) 지금(주거 9% 손실, 끝이 10% 늦음)* 2) 더 아프게(탄 시설 수리비 2배, 불이 위층으로도) 3) 방재 시설을 더 싸게
9. **끊긴 문장**("…예를 들면 뭐 밀을 기르고") — 무슨 시스템을 말하려던 것인지. 1) 성채 안 농사(옥상 텃밭을 키워 곡물·채소 사슬로) 2) 다른 것(말해 주기) 3) 잊어도 됨
10. **끝의 크기** — 1) 옥상 황제 80 + 구청(봇 36일 ≈ 사람 10~12시간)* 2) 60(봇 31일) 3) 90(봇 37일+)
11. **층이 열리는 문턱** — 1) 아래층 80%* 2) 70%(느긋하게 해도 2층이 이틀 빨리 열림)
12. **다음에 힘줄 곳**(둘까지) — 1) 직접 줍기 던전 늘리기(폐공장·철거 현장) 2) 도시 그림 디테일(4~5계층 집, 내부) 3) 후반 콘텐츠(사건·정책·명소) 4) 성능·다듬기 5) 모바일 간소판

v0.3에서 물었던 것(돈 쓸 곳, 속도, 방치 정산, 그래픽)은 PC판으로 오면서 A23·§4로 대체됐다.

## 8. 알려진 문제

1. **후반 속도**: 규칙 한 스텝이 집 1,800채에서 57ms. ×4에서 끊길 수 있다. 다음에 줄일 곳은 정해 두었다(알림 집계, 위험 순회).
2. **방재 무시의 값이 목표보다 약하다**: 끝이 10% 늦는 데 그친다(목표 20%). 더 올리면 방치한 도시가 무너져서 멈췄다 — §7 질문 8.
3. **느긋하게 하면 초반이 길다**: 2층이 9일째(×1로 1시간 반)에 열린다 — §7 질문 11.
4. **직접 줍기에서 쓰러질 일이 적다**(보통 성격 10%, 목표 15~22%). 고물이 들고 나온 것의 37%라 "승급에 쓸 자재"로는 자동 파견의 1.4배쯤.
5. **현황판의 긴 줄이 1280×720에서 잘린다**("…모자란다 — 물탱크를 …"). 1920에서는 다 보인다.
6. 웹에서 직접 줍기는 확인 대본이 줍줍 본부를 못 놓아 열어 보지 못했다(데스크톱에서는 같은 코드로 통과).
7. 목적지 8곳 중 6곳은 고물 야적장 그림을 빌려 쓴다. 4~5계층 집은 옛 그림.
