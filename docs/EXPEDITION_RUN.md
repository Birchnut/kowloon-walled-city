# 직접 줍기(탐험 개편) — 시제품 설계 v0 (디렉터)

근거: Jin, 2026-11-11 — "보내 놓고 시간 지나면 누르는 시스템은 효과적이지 않고 재미도 없다. 직접 인게이지하는 느낌… 던전을 고르고 직접 파밍하고 위험한 건 피하고, 몬스터를 제압하고 보스까지 잡으면 최대 보상, 못 잡으면 중간 보상. 탐험 자체가 또 하나의 게임 장르로서 재미가 있어야 한다."
이 문서는 **던전 하나짜리 시제품**의 설계다. 재미는 조작감에서 나오므로 문서가 아니라 시제품으로 판단한다. 형식은 Jin이 고르지 않아 디렉터가 "추출형 줍기"로 정했다(A27) — 해 보고 바꾼다.

## 1. 한 판의 모습 (3~6분)
1. **고른다**: 지도에서 던전을 고른다. 던전마다 주로 나오는 것, 남은 재고(%), 위험도가 보인다.
   | 던전 | 주로 나오는 것 | 분위기 |
   |---|---|---|
   | 고물 야적장 | 철제·고물·전자 폐품 | 쌓인 차체, 압축기 |
   | 쓰레기 매립지 | 목재·헌 옷·통조림 | 쓰레기 산, 들개 |
   | 철거 현장 | 콘크리트·철근 | 무너지는 바닥 |
   | 폐공장 | 설비 부품·전자 폐품 | 경비, 누전 |
   | 폐기물 처리장 | 희귀품·도면 (가장 위험) | 독성 웅덩이 |
2. **들어간다**: 위에서 내려다보는 화면. 방 6~8개가 갈래길로 이어지고, 깊을수록 좋은 것이 나오고 위험하다.
3. **뒤진다**: 더미 앞에서 E를 누르고 있으면 뒤진다(0.6~1.5초). 뒤질 때와 싸울 때 **소란**이 오른다. 소란이 차면 더 몰려온다 — 오래 머물수록 위험해진다.
4. **고른다(배낭)**: 배낭은 6칸. 자재 묶음 하나가 한 칸. 꽉 차면 버리고 바꿔 담는다 — 목재를 담을지 철제를 담을지가 곧 도시 계획이다.
5. **피하고 싸운다**: 쥐 떼, 들개, 경비원(손전등 시야 안에 들면 쫓아온다), 경쟁 고물상. 무너지는 더미, 독성 웅덩이, 누전.
6. **나갈지 더 갈지**: 출구는 입구와 중간에 하나. 나가면 배낭 전부가 내 것. 쓰러지면 절반을 잃고 줍는 이는 다친다(게임 시간으로 회복, 의원이 있으면 빨리).
7. **두목**: 맨 안쪽 방. 잡으면 배낭 밖의 **큰 짐**(도면·설비 부품 묶음·명소 조각·특수 주민)과 최대 보상.

## 2. 조작 (PC)
WASD 이동 · 마우스 조준 · 왼쪽 클릭 휘두르기(쇠파이프) · 오른쪽 클릭 던지기(깡통·벽돌, 주운 것) · Space 구르기 · E 뒤지기/줍기/문 · Tab 배낭 · Esc 멈춤.
총은 없다 [디렉터 — 고물 줍는 사람의 싸움은 파이프와 던지기가 어울린다. 조작감이 심심하면 새총·못총을 더한다].

## 3. 도시와 잇는 장치
| 방향 | 장치 |
|---|---|
| 도시 → 줍기 | 줍줍 본부의 등급 = 배낭 칸·동행 수 / 고물 분해소에서 장비(헬멧, 좋은 파이프) / 의원 = 부상 회복 / 연구 = 던전 지도·새 던전 |
| 줍기 → 도시 | 자재·전자 폐품·설비 부품, 도면(새 시설), 거래처, 특수 주민, 명소 조각 |
| 시간 | 줍는 동안 도시는 ×1로 계속 돈다(건설·입주가 진행). 불 같은 큰 일은 화면 구석에 뜨고 "돌아갈까"를 묻는다 |
| 관문 | 던전의 재고는 털면 줄고 게임 시간으로 다시 찬다 — 같은 곳만 계속 털 수 없다 |
| 자동 파견과의 관계 | 자동 파견은 같은 던전 재고를 조금씩, 안전하게. 직접 줍기는 같은 시간에 2~3배 + 자동으로는 안 나오는 것 |

규칙 층과는 명령 둘로만 만난다: `run_begin {dest}` → `{stock, danger, seed}` / `run_result {dest, loot, outcome, finds}` (`docs/ARCHITECTURE.md` v4).

## 4. 시제품 v0의 범위
- 던전 1곳(고물 야적장), 방 틀 8~10종을 이어 붙여 매번 다르게.
- 적 3종(쥐 떼·들개·경비원), 위험 2종(무너지는 더미·누전), 두목 1(압축기 "큰형").
- 배낭 6칸, 출구 2곳, 휘두르기·던지기·구르기, 소란 게이지, 결과 화면 → `run_result`.
- 그림은 가진 CC0 묶음 + 코드로 그린 픽셀. 소리는 합성음.
- **자동 플레이어**: 간단한 규칙으로 한 판을 끝까지 하는 봇을 같이 만든다 — 수백 판을 돌려 "한 판에 무엇을 얼마나 들고 나오는가"의 분포를 얻고, 그 분포를 도시 봇 시뮬레이션에 넣어 속도를 맞춘다(액션은 손으로만 검증하면 수치가 감이 된다).
- 화면 확인은 입력 대본 + 스크린샷, 손맛은 Jin이 직접.

## 5. Jin이 해 본 뒤 고를 것 (미리 적어 둠)
1. 싸움의 비중: 지금처럼 피하기 중심 / 더 슈터답게(원거리 무기·몰려오는 적) / 싸움 없이 잠입과 선택만.
2. 한 판 길이: 3분 / 5분 / 10분.
3. 쓰러졌을 때: 절반 잃음 / 전부 잃음 / 다친 시간만.
4. 자동 파견을 남길지.
