### 설정집에 대해 알아 둘 것
- 설정집은 일곱 탭짜리 문서다. **이전 대화에 첨부된 .docx에는 ① 탭(땅·역사·권력)만 들어 있었다.** 게임에 가장 직접 닿는 ⑤ 먹고 사는 일(음식·물·교역·직업·물가), ⑥ 물건·시설 도감, ⑦ 사료·게임 메모(게임 메모, 승인받을 결정 목록)는 못 봤다 → Jin에게 전체를 다시 받아야 한다(문서 링크 또는 탭별 내보내기).
- 저장소는 공개라서 설정집 원문은 커밋하지 않았다. 넣으려면 Jin에게 먼저 묻는다.
- ① 탭에서 확인한 뼈대:
  - 시점: 1972년 겨울(민력 17년). 회수하지 못한 수소폭탄("잠든 해") 위의 네모난 무법 도시. 탄두는 실제로 있고, 게임의 숨은 리셋으로 열어 둠.
  - 계층: 벽틈시민 → 판자시민 → 성채민 → 온수민 → 청공시민 (잠자리·주식·마시는 물·한 달 벌이 표가 있다). 지금 게임의 이름(굴러온 돌 → 월세 전사 → 박힌 돌 → 깡통 귀족 → 옥상 황제)과 다르다.
  - 정부: 방백(장부관, 시장)과 네모청 — 장부로 다스린다. 화폐는 명주항 달러(바깥 돈).
  - 두 조직: 십삼요회·연우당(하나는 도박, 하나는 아편·전화 사기·총기), 사층 협정(1968).
  - 신앙: 민일교(잠든 해), 고요시간(새벽 3시 12분), 안면제.
  - 물: 빗물·우물물 → 단물 → 바깥물. 음식: 맹관죽·빵술 → 토끼버거·완자·눌림떡 → 완탕면·묻지마 덮밥 → 부속 구이·거위 구이·옥상 달걀 → 스시·꼬냑.
  - 구조: 받침집·받침값, 길품·건너방, 높이의 규칙, 층마다 있는 것.
  - 그림: 장면은 잉크 스케치 + 종이 질감, 손글씨 캡션(문서 안에 12장).
