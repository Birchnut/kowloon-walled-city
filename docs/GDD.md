## 1. 한 줄 정의 & 핵심 판타지

**한 줄 정의**
황무지 한 귀퉁이 12×12칸 부지에 단칸방 하나를 놓고, 세금을 걷고 방향만 정해주면 사람들이 알아서 켜켜이 쌓아 올리는 입체 성채 운영 게임. 모바일 세로, 픽셀아트, 낮과 밤. `[확정]`

**핵심 판타지 (Jin 원안 그대로)**
- 하나의 구룡성채 모습은 없다. 세기말 목가적 농장과 나무집의 성채일 수도, 사이버펑크 범죄경제 성채일 수도, 콘크리트 유토피아일 수도 있다.
- "원하는 모습을 노리고 플레이할 수도 있고, 원하는 경제를 만들다 보니 그 모양이 될 수도 있다. 어쨌든 유기적이어야 한다."
- 플레이어는 시장이 아니다. 완벽한 지배력은 없지만 사람들의 방향성을 정해주는 **대장**이다.
- 멀리서 보면 기괴한 콘크리트 덩어리, 확대하면 국숫집 아주머니가 손님을 맞고 아이들이 옥상에서 노는 모습. `[참고: GPT안]`

**한 달 뒤 약속**
단칸방 하나 → 30일 뒤 8~10층 성채. 같은 시작점에서 플레이어마다 실루엣·골목·빛·소리가 다른 성채가 나와야 한다. 이게 안 나오면 다른 시스템은 전부 의미 없다.

**첫 테스트에서 확인할 것** `[참고: GPT안]`
1. 같은 정책 조합에서도 성채 모양이 매번 조금 다른가 (유기성)
2. 다른 정책 조합이면 20분 뒤 확연히 다른 성채인가 (분기)
3. 징수 다 끝낸 뒤에도 플레이어가 성채를 잠깐 더 구경하는가 (애착)

## 3. 플레이어 — 호칭 변화 시스템

### 3.1 역할 정의
- 플레이어는 첫 가옥을 세운 사람. 공동 창고와 입구를 관리하다 보니 세금을 걷고 방향을 정하는 사람이 됐다. `[참고: GPT안]` (권한의 자연스러운 근거)
- 시스템 직책 이름은 화면에 거의 안 뜬다. 주민이 부르는 **호칭**이 곧 플레이어의 정체. `[확정]` 호칭은 도시 성향에 따라 변한다.

### 3.2 호칭 테이블 `[Claude 제안]` — 호칭 단어 자체는 18장 미정 #4

| 단계 | 조건 (전부 `[플레이스홀더]`) | 호칭 후보 | 주민 대사 톤 |
|---|---|---|---|
| 0 | 게임 시작 ~ 인구 10 | **대장** | "대장, 비 새는데요" |
| 1 | 인구 10+ 이고 지배 성향 없음 | 대장 (유지) | — |
| 2-농 | 농업 수입 비중 1위 + 공동부조 ON | **촌장** / 어르신 | "촌장님, 올해 배추가…" |
| 2-제 | 제조 수입 비중 1위 | **반장** / 공장장 | "반장님, 발전기 또 죽었어요" |
| 2-오 | 오락 수입 비중 1위 + 네온경관 | **회장님** / 사장님 | "회장님, 오늘 매출 찍었습니다" |
| 2-음 | 음성 수입 비중 1위 | **따거** / 큰형님 | "따거, 윗선에서 연락 왔습니다" |
| 3 | 2단계 유지 + 위신 상위 | 성향별 존칭 강화 (예: 촌장→어르신, 따거→大哥) | — |

- 골격 `residents.json`의 `player_titles.by_condition`은 현재 3개: 따거(underground) / 회장(manufacturing, 인구 60+) / 촌장(agriculture). **오락 호칭이 없고, 회장이 제조에 붙어 있다** — 위 표와 다름. 어느 쪽이든 미정 #4에서 정하면 JSON에 맞춘다.
- 성향 판정은 **최근 7일 수입 비중** `[플레이스홀더]` 기준 (골격 필드명 `dominant_category`). 하루 단위로 뒤집히지 않게 히스테리시스(1위가 2위보다 15%p 이상 앞설 때만 교체) `[플레이스홀더]`.
- 호칭이 바뀌는 날은 하루 끝 제안 카드 대신 **호칭 변경 연출**이 한 장 끼어든다. 주민들이 새 호칭으로 부르기 시작하는 짧은 컷.
- 호칭은 UI 상단 플레이어 이름 옆에 붙고, 대표인물 대사의 호격에 쓰인다.

### 3.3 권한 범위
**할 수 있는 것**
- 정책 패널 4축 조정 (상시)
- 징수 (말풍선 탭)
- 하루 끝 제안 카드 3장 중 선택 (1장 선택 또는 전부 보류)
- 칸 단위 **보존** 토글 (8.4절)
- 감상 모드 (시간대 선택, 스크린샷)

**못 하는 것** `[확정]`에서 도출
- 특정 칸에 특정 건물 짓기 (직접 증축 아님)
- 구획 지정 (심시티식 아님)
- 특정 개인을 콕 찍어 추방·입주 (정책으로만)

### 4.3 첫 경제활동 3지선다 `[Claude 제안]` — 구성은 18장 미정 #3
진영 선택이 아니다. 나중에 전부 할 수 있지만 **첫 투자가 첫 이웃·첫 자재·첫 외형에 흔적을 남긴다.** `[참고: GPT안]`

| 카드 | 즉시 효과 | 첫 유입 가구 | 첫 외형 흔적 | 열리는 축 |
|---|---|---|---|---|
| **텃밭과 빗물통** | 느리고 꾸준한 식량, 자재 소모 적음 | 할매, 농사꾼 가구 | 옥상 화분, 물통, 덩굴 | 농업 |
| **고물 작업대** | 폐자재 → 건축자재·소액 판매 | 봉씨, 수리공 가구 | 부품 더미, 안테나, 철판 | 제조 |
| **노점과 마작판** | 당장 현금, 밤에 사람 몰림 | 리 사장(초기형), 떠돌이 | 천막, 전구 줄, 간이 테이블 | 오락 (음성은 조건 해금) |

- 음성 산업은 오프닝 카드에 없음. 오락 허가 + 외부 접촉 조건으로 해금 (13장). 이유: 첫 5분에 "보이스피싱 콜센터"가 뜨면 풍자가 아니라 장르 선언이 되어버림. **Jin이 처음부터 넣기를 원하면 미정 #3에서 선택.**

## 5. 공간 — 부지·층·뷰

### 5.1 그리드 `[확정]` 12×12 × 최대 8~10층
- 셀(cell) = 방 1칸 = 건축 최소 단위. 셀 하나에 가구 1 또는 사업체 1 (큰 사업체는 2~4셀 점유).
- 좌표 `(x, y, z)`. z=0 지상. z 최대 `[플레이스홀더] 9`.
- 셀 상태: 빈 땅 / 건축 중 / 점유 / 공용(골목·계단·마당·옥상정원) / 보존 / 폐허.
- **지지 규칙**: z>0 셀은 바로 아래 셀이 점유 또는 공용(계단·다리)이어야 한다. 캔틸레버는 설비수준 상위에서 해금 `[Claude 제안]`.
- **채광 값**: 셀 위로 하늘까지 빈 셀 수 + 인접 빈 셀 수로 계산. 주거 선호에 영향. 어두운 셀은 창고·버섯 재배·콜센터가 선호 (모든 조건을 벌점으로 만들지 않기 `[참고: GPT안]`).
- **접근 값**: 지상 또는 계단·골목 셀까지 최단 거리. 상점은 접근 높은 셀 선호.
- 부지 가장자리 12×12 바깥 1칸은 "길"로 고정 렌더링 (유입 인구가 걸어오는 곳, 외부 거래 트럭이 서는 곳).

### 5.2 카메라 `[확정]` 아이소 외관 + 탭하면 구역 단면
- 기본: 아이소메트릭 전경. 세로 화면이라 성채가 화면 위 2/3, 아래 1/3은 정책 패널·징수 알림 영역.
- 핀치 줌 2단계: 전경(실루엣 감상) / 근접(가구 단위 디테일, 말풍선 탭 가능).
- 구역 탭: 해당 x열(또는 y열)을 **단면 뷰**로 전환. 외벽을 벗기고 층별 내부(가구·사업체·설비)를 보여준다.

### 5.3 가려진 내부 선택 문제 — UX 선택지 (18장 미정 #1)
성채가 커지면 앞쪽 건물이 뒤쪽을 가린다. 징수 말풍선이 뒤에 숨은 셀에 뜨면 못 탭한다. 초기에 풀어야 할 과제 `[확정]`.

| 번호 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **1** | **층 슬라이더**: 화면 오른쪽 세로 슬라이더로 표시 최고층 조절. 그 위는 사라짐 | 구현 쉬움, 직관적 | 수평 방향 가림은 못 풀음. 슬라이더가 엄지 영역 차지 |
| **2** | **탭하면 앞쪽 반투명**: 셀을 길게 누르면 그 셀과 카메라 사이 건물이 50% 투명 | 전경 유지, 조작 하나 | 픽셀아트에 반투명은 지저분해질 수 있음. 셰이더 필요 |
| **3** | **단면 전환 버튼**: 하단 버튼으로 "외관 / X단면 / Y단면" 3상태 토글. 단면은 가장 바깥 열부터 스와이프로 한 칸씩 안으로 | 단면 자체가 보기 좋음(건축 도면 느낌). 확정안과 가장 맞음 | 한 번 더 조작. 징수 말풍선은 단면에서만 탭 가능해지면 번거로움 |
| **4** | **징수는 뷰와 분리**: 가려진 셀의 말풍선은 하단에 **징수 큐** 아이콘으로 모아 보여주고 거기서 탭. 뷰는 2 또는 3으로 | 징수 끊김 없음 | 성채 위를 직접 탭하는 손맛이 줄어듦 |

- `[Claude 제안]` 3+4 조합을 추천. 이유: 단면 뷰는 확정 사항이고, 징수가 뷰에 묶이면 성채가 클수록 징수가 짜증나기 때문. 하지만 **Jin이 고른다.**

## 6. 코어 루프 (하루치)

### 6.1 루프 `[확정]` 순서
```
접속 → [경과 요약] → 징수 (말풍선 탭, 부패 타이머) → 정책 패널 조정 (선택)
     → 자동 성장 관찰 (도시 시계 흐름) → 하루 끝: 제안 카드 3장 → 저장
```

### 6.2 징수 — 그밸식 타이머 + 부패 `[확정]`
- 각 사업체는 생산 주기마다 **말풍선**을 띄운다 (코인·식량·자재 아이콘). 골격 `economy.harvest`: `ripe_after_hours=8` → 익음(징수 가능), `spoil_after_hours=20` → 부패 시작, `spoil_loss_ratio=0.5`, `max_pending_days=2`. 전부 `[플레이스홀더]`. 골격은 전 업종 공통값 하나이고, GDD는 업종별 차등을 제안 (16.3 `harvest_cycle_hours`).
- 부패 표현: 아이콘이 시들고 파리 날아다님. 골격 기준 손실 50%, 그 뒤 `max_pending_days` 지나면 소멸.
- 농업은 부패 빠름(실제 음식), 제조는 느림(재고), 오락은 "손님이 돌아감", 음성은 "장부가 사라짐 / 윗선이 떼어감". 부패 표현도 업종별 풍자.
- 가구는 세금 말풍선 (하루 1회, 부패 없음, 대신 미납 누적 시 불만).
- **랜덤 성과** `[확정]`: 징수 탭 시 낮은 확률 `[플레이스홀더] 5%`로 보너스 드롭 (희귀 자재, 외형 장식 아이템, 대표인물 쪽지). 그밸 NPC 작업 드롭 차용.
- 한 번에 몰아서 탭하는 피로를 줄이기 위해 **길게 누르면 화면 안 말풍선 일괄 징수** `[Claude 제안]`.

### 6.3 정책 패널 (상시)
- 하단 1/3 영역. 4축 탭. 각 축은 토글/라디오 (7장).
- 정책 변경은 **즉시 적용되지만 효과는 느리게** — 유입 구성은 다음 날부터, 외형은 신규 건축부터. 바꾼 걸 바로 못 느끼면 재미 없으니 패널에 "내일 예상 유입: 농사꾼↑ 떠돌이↓" 미리보기 `[Claude 제안]`.

### 6.4 하루 끝 제안 카드 3장 `[확정]`
- 도시 시계 저녁에 자동 등장. 카드 = 도시가 "이렇게 자라려 한다"는 제안. 승인 1장 / 전부 보류 가능.
- 카드 종류: 증축 (어디에 몇 칸, 어떤 자재) / 설비 (발전기, 물탱크, 네온) / 사업체 입점 (허가 산업 내) / 공용공간 (마당, 다리, 옥상정원) / 사건 대응 (화재, 민원, 외부 압력).
- 카드는 **왜** 이게 뜨는지 한 줄 설명 포함: "작업장에 일자리가 늘어 인근에 주거 3칸을 증축하려 함. 자재는 목재." `[참고: GPT안]`
- 보류한 카드는 사라진다. 다음 날 비슷한 게 다시 뜰 수 있다.
- 접속 안 한 날의 카드는 **쌓이지 않는다**. 도시는 카드 없이도 느리게 자란다 (14장 오프라인 규칙).

### 6.5 세션 길이별 모습

**5분 세션 (출근길)**
1. 경과 요약 팝업 (밤사이 수입, 새 입주 2가구, 노점 하나 문 닫음) — 10초
2. 말풍선 일괄 징수 — 30초. 부패 직전 아이콘 2개 발견, 아슬아슬
3. 정책 패널은 안 열고 넘어감
4. 하루 끝 카드 3장 → 1장 선택 — 40초
5. 밤 전경 10초 구경, 종료. 저장은 자동.

**15분 세션 (저녁)**
1. 경과 요약 → 징수 (2분)
2. 정책 패널 열어서 입주·돌봄을 "노동우선"에서 "공동부조"로 변경. 미리보기에서 "비노동 가구 유입↑, 세금 수입↓, 위신↑" 확인 (2분)
3. 도시 시계 1일을 지켜본다 (6분, 15장). 낮에 할매가 옥상에 화분 놓는 모습, 저녁에 네온 켜지는 순간
4. 단면 뷰로 3층 콜센터 안을 들여다본다. 블라인드 쳐진 방에 책상 6개 (1분)
5. 제안 카드 3장 중 "4층 북측 다리 연결" 선택. 반투명 고스트로 모습 미리보기 (1분)
6. 감상 모드로 밤 시간대 고정, 스크린샷 한 장 (1분)
7. 보존 토글: 첫 가옥과 할매 텃밭 셀에 핀 (1분). 종료.

## 7. 정책 4축 상세

`[확정]` 4축과 옵션 이름은 Jin이 명명한 그대로. 효과 숫자는 전부 `[플레이스홀더]`. 안전/자유/외부위협 3분할은 `[참고: GPT안]` (치안 하나로 뭉개지 않기).

### 7.1 산업 허가 — 농업 / 제조 / 오락 / 음성
각 산업은 **금지 / 허가 / 장려** 3단계 `[Claude 제안]` (미정 #5: 2단계 on/off로 갈지). 장려는 세금 감면 대신 유입 가중치↑.

| 산업 | 유입 인구 구성 | 수입 | 위신 | 외형 레이어 | 안전 / 자유 / 외부위협 |
|---|---|---|---|---|---|
| **농업** | 농사꾼 가구, 가족 단위, 노인 비율↑ | 낮지만 부패 빠른 식량 수입. 식량 자급률↑ → 외부 식량 구매비↓ | +0.5/셀 (녹지) | 화분, 덩굴, 빗물통, 목재 비계, 닭장 | 안전↑ / 자유 보통 / 외부위협↓ |
| **제조** | 노동자 가구, 수리공, 단신 남성↑ | 중간, 안정적. 자재 자체 생산 | −0.5/셀 (소음·연기) | 환풍구, 굴뚝, 철판, 발전기, 전선 다발 | 안전↓(산업재해) / 자유 보통 / 외부위협 보통 |
| **오락** | 서비스업자, 떠돌이, 외부 방문객(비거주) | 높음, 밤에 집중, 변동 큼 | 네온경관 시 +1/셀, 아니면 0 | 네온, 간판, 전구 줄, 천막, 뒷문 | 안전↓(취객) / 자유↑ / 외부위협 보통 |
| **음성** | 중개인, 조직원, 불안정 노동력, 가족 단위↓↓ | 매우 높음. 단, 외부위협 이벤트로 한 번에 깎임 | −2/셀 | 블라인드, 위성 안테나, 철문, 경비초소, 24시간 불빛 | 안전↑(내부 통제) / 자유↓↓ / 외부위협↑↑ |

- 음성 산업의 함정 `[참고: GPT안]`: 처음엔 세금 많이 내는 사업자가 들어와 재정이 좋아진다. 시간이 지나면 숙소와 경비까지 장악. 금지로 바꾸면 수입 급락 + "따거, 이러시면 안 됩니다" 이벤트. 돈은 쉽게 벌었지만 주도권을 넘겨준 구조.
- 범죄 도시라도 내부는 강하게 통제돼 도난이 적을 수 있다 → 안전↑ 자유↓↓. 이게 "치안" 하나로는 못 표현되는 부분.

### 7.2 입주·돌봄 — 누구나 / 노동우선 / 추방 / 공동부조
라디오 (하나만 선택). 유입 인구 중 ~20% 비노동 `[확정]`을 어떻게 다루느냐.

| 옵션 | 유입 인구 구성 | 수입 | 위신 | 외형 레이어 | 안전 / 자유 / 외부위협 |
|---|---|---|---|---|---|
| **누구나** | 유입량 최대. 비노동 20% 그대로 들어옴 | 세금 기반 넓지만 1인당 낮음. 식량 압박 | 0 | 빨래 많음, 임시 천막, 복도에 짐 | 안전↓(과밀) / 자유↑ / 외부위협 보통 |
| **노동우선** | 노동 가능자만. 비노동은 문 밖 대기 | 단기 생산 최대 | −1 (문 밖 줄) | 정돈됨, 숙소형 외관, 공용공간 적음 | 안전 보통 / 자유 보통 / 외부위협 보통 |
| **추방** | 비노동 인구 추방. 그 가족이 같이 떠날 확률 `[플레이스홀더] 40%` | 부양비 0. 하지만 숙련 가구 이탈 리스크 | −3, 이벤트 시 추가 | 철문, 경비초소, 빈 방 | 안전↑ / 자유↓ / 외부위협↑(소문) |
| **공동부조** | 비노동 포함 전부. 돌봄 종사자 가구 유입 | 세금에서 부조 기금 차감 `[플레이스홀더] 15%` | +2 + 공용공간 보너스 | 야매 진료소, 공동 부엌, 마당, 벤치 | 안전↑ / 자유↑ / 외부위협↓ |

- **결과는 구성에 따라 달라진다** (10.4절). 추방이 항상 기술자 이탈을 부르면 도덕 퀴즈. 음성 도시에서 추방은 거의 조용히 지나가고, 농업 도시에서 추방은 가족 단위 이탈이 크다.

### 7.3 세금·투자 우선순위 — 증축 / 생활환경 / 설비
세금은 하루 징수. 세율은 **낮음/보통/높음** `[Claude 제안]` + 투자 우선순위 라디오.

| 투자 우선 | 성장 예산 배분 `[플레이스홀더]` | 유입 구성 | 위신 | 외형 | 안전 / 자유 / 외부위협 |
|---|---|---|---|---|---|
| **증축** | 70% 신규 셀 / 15% 환경 / 15% 설비 | 유입 수용량↑ → 인구 빠르게↑ | −0.5 (과밀) | 층이 빨리 올라감, 캔틸레버, 임시 자재 | 안전↓ / 자유 보통 / 외부위협 보통 |
| **생활환경** | 20 / 60 / 20 | 가족 단위, 장기 거주 가구↑ | +2 | 마당, 다리, 창문 큼, 채광 유지 | 안전↑ / 자유↑ / 외부위협↓ |
| **설비** | 20 / 20 / 60 | 기술자, 상위 업종↑ | +1 (네온경관 시 +2) | 발전기, 물탱크, 전선, 네온, 자동문 | 안전↑ / 자유 보통 / 외부위협 보통 |

- 세율 높음: 수입↑, 가구 불만↑, 자유↓, 일부 가구 세금 회피(징수 말풍선 안 뜸) `[참고: GPT안]` 주민에게 이해관계가 있다는 원칙.

### 7.4 자재·외관 — 목재우선 / 철판 / 네온경관 / 외벽녹화
라디오. 신규 건축의 **기본 자재**와 **외장 성향**을 정한다. 기존 셀은 바뀌지 않음 (지층이 남는다 `[참고: GPT안]` 도시의 지층).

| 옵션 | 유입 구성 | 수입 | 위신 | 외형 레이어 | 안전 / 자유 / 외부위협 |
|---|---|---|---|---|---|
| **목재우선** | 농사꾼, 가족, 공동체형 | 자재비 낮음. 화재 리스크 | +1 (따뜻함) | 판자, 오두막, 목재 비계, 풍력기, 물레방아(수로 조건) | 안전↓(화재) / 자유↑ / 외부위협↓ |
| **철판** | 노동자, 수리공 | 자재비 중간. 제조 산업 시너지 | −1 (차가움) | 골판 철판, 리벳, 녹, 굴뚝 | 안전 보통 / 자유 보통 / 외부위협 보통 |

## 8. 자동 성장 규칙 (알고리즘 스케치)

`[확정]` 플레이어는 정책만 정하고 도시가 어디에 뭘 지을지 알아서 결정한다.

### 8.1 하루 1회 성장 틱
```
매 도시일 저녁:
  budget = 세금 수입 × 투자 비율(7.3)
  demand = { 주거: 대기 인구 / 셀당 수용, 사업체: 허가 산업별 수요, 공용: 위신 정책 }
  candidates = 빈 셀 중 지지 규칙 통과한 것
  각 candidate에 대해 용도별 점수 계산 (8.2)
  상위 3개 (용도, 셀 묶음) → 제안 카드 3장
  플레이어 승인 → 다음 날 아침 건축 완료
  미접속 시 → 1위 카드만 자동 실행 (느린 성장)
```

### 8.2 셀 점수 (용도별 가중치 `[플레이스홀더]`)

| 요소 | 주거 | 상점/오락 | 작업장/제조 | 음성 | 농업 | 공용 |
|---|---|---|---|---|---|---|
| 채광 (5.1) | +3 | +1 | 0 | **−2** (어두운 곳 선호) | +4 | +2 |
| 접근 (5.1) | +1 | +4 | +2 | −1 (뒷골목 선호) | 0 | +3 |
| 제조 인접 | −2 | 0 | +2 (집적) | 0 | −1 | −2 |
| 오락 인접 | −1 | +2 | 0 | +1 | 0 | 0 |
| 음성 인접 | −2 | 0 | 0 | +2 | 0 | −3 |
| 농업 인접 | +1 | 0 | 0 | 0 | +1 | +1 |
| 높이 (z) | −0.3/층 | −0.5/층 | −0.5/층 | +0.2/층 | +0.5/층 (옥상) | 옥상 +3 |
| 공간 압력 (대기 인구↑) | +2 | 0 | 0 | 0 | 0 | −1 |
| 자재 정책 일치 | 자재별 보정 | | | | | |

- 설비 가중치: 전력 공급 셀 범위 안이면 상점/오락/음성 +2. 물 공급 범위 안이면 주거/농업 +2.
- 점수에 소량 노이즈 `[플레이스홀더] ±15%` → 같은 정책이라도 매번 다른 성채 (1장 테스트 1).

### 8.3 성장 미리보기
- 제안 카드를 누르면 성채 위에 **반투명 고스트** 셀이 뜬다. 자재·업종에 따라 고스트 외형도 다름 (9장 레이어 중 자재+업종 레이어만).
- 승인 → 밤사이 건축 중 비계 → 아침 완성.

### 8.4 보존 토글
- 셀 길게 누르기 → 📌 보존. 보존 셀은: 건축 대상 제외, **바로 위 셀도 건축 제외** (채광 보호) `[Claude 제안]` (미정 #7: 위 보호 범위).
- 보존 셀 수 제한 `[플레이스홀더] 인구/10`. 전부 보존하면 성장 멈춤 → 제한 필요.
- 첫 가옥은 기본 보존 (튜토리얼에서 핀 찍는 걸 가르침).

### 8.5 큰 변화는 반드시 카드로
- 중정·마당을 메우는 증축, 보존 셀 인접 증축, 5층 이상 신규 층, 음성 사업체 입점은 **자동 실행 금지**. 미접속 중에도 카드로 남아 복귀 시 처리 `[참고: GPT안]` "자생이 내 설계를 멋대로 망치면 안 된다".

## 9. 외형 레이어 합성

`[확정]` 자재 × 업종 × 설비수준 × 주민취향 × 건물나이. 셀 하나의 스프라이트는 아래 레이어를 순서대로 겹쳐 그린다.

### 9.1 레이어 스택 (아래 → 위)

골격 `visual_rules.json`의 `layer_order`를 따른다. 골격에 없는 `glow`는 추가 제안 (16.3).

| 순서 | 레이어 키 | 입력 | 예시 타일 |
|---|---|---|---|
| 0 | `base` | 자재 (`material`) | 바닥·골격 |
| 1 | `wall` | 자재 | 판자 벽, 철판, 콘크리트 |
| 2 | `window` | 업종 카테고리 | 산업용 창, 쇠창살(`window_barred`, 음성), 블라인드 |
| 3 | `sign` | 자재 네온 / 업종 / 취향 | 네온 띠, 큰 네온 간판, 작은 네온, 간판 없음(음성) |
| 4 | `utility` | `utility_level` 0~3 | 전선 → 배관+전선 → 에어컨, 환풍구(제조) |
| 5 | `decor` | `taste` + 업종 | 화분(농업), 덩굴(녹화), 안테나(tinker), 깃발·제단(commune), 빨래, 고양이 |
| 6 | `wear` | `age_band` | `worn` 얼룩 → `old` 녹·균열 |
| 7 | `glow` `[Claude 제안]` | `utility_level` + 업종, 밤에만 | 창 불빛, 네온, 전구 줄, 블라인드 틈 흰 빛 |
| — | 상태 오버레이 (레이어 아님, 이펙트) | 부패/화재/공사 | 파리, 연기, 비계 |

- 규칙은 `rules[].{when, layers}` 누적 평가. `when`이 전부 맞으면 `layers`를 덮어쓴다 (뒤 규칙이 앞 규칙을 덮음). 코드는 `layer_order` 순서로 그리기만 한다.
- 혼합 예시: `wall_wood_plank` + `window_barred` + `sign_neon_big` + `util_wires` + `decor_flags` + `wear_stains`. 목조 판자집에 쇠창살 치고 네온 간판 단 카지노. `[참고: GPT안]`
- 세부 흔적 (고추 말리기, 낙서, 담배꽁초)은 `taste` 4종 아래 서브태그가 필요 → 16.3 추가 제안.

### 9.2 낮/밤 변형
- 레이어 0~6은 조명 틴트만 바뀜 (낮 흰색 → 저녁 주황 → 밤 남색).
- 레이어 7은 밤에만 알파 1.0. 저녁 전환 때 **순서대로 켜진다** (아래층부터, 또는 전력망 연결 순서). "첫 전기의 밤" 연출 `[참고: GPT안]`.
- 비: 전 레이어 위에 빗줄기 파티클 + 차양 펼침 상태 전환.

## 10. 주민

### 10.1 단위 `[확정]` 가구/사업체 + 대표인물 소수
- **가구**: 1~4명, 셀 1개 점유. 속성: 유형(농사꾼/노동자/서비스업/기술자/조직원/비노동), 취향 태그(외형 레이어 4), 불만도, 세금 미납 누적.
- **사업체**: 1~4셀 점유. 속성: 업종(11장), 설비수준, 생산 주기, 고용 수, 말풍선 상태.
- **대표인물**: 가구 또는 사업체에 붙은 이름 있는 인물. 대사·부탁·이벤트 트리거. v1에 5~7명.

### 10.2 유입 흐름 `[참고: GPT안]` 두 흐름 분리
1. **일자리 보고 오는 사람**: 허가 산업·세율·위신에 반응. 구성은 7장 표.
2. **갈 곳 없는 사람**: 도시 규모에 비례해 꾸준히 (Jin 원안). 하루 유입 = `인구 × 0.05 + 1` `[플레이스홀더]`. 이 중 ~20%가 비노동 (골격 `housing_care` 옵션의 `nonworker_ratio`).

### 10.3 대표인물 초안 (7명) `[Claude 제안]` — 이름·구성은 미정 #8

골격 `residents.json`에는 이미 3명이 들어가 있다: **복 할매**(`granny_bok`, 첫 입주민, 비노동) / **최 기사**(`mr_choi`, 전기·배선) / **린 언니**(`sister_lin`, 마작방). 아래 표의 할매·봉씨·리 사장과 **역할은 같고 이름만 다르다.** 골격 이름을 표에 병기.

| 이름 (골격 ID) | 역할 | 등장 조건 | 부탁하는 것 | 건물에 남기는 흔적 |
|---|---|---|---|---|
| **춘자 이모** (신규) | 국숫집. 첫 사업체 후보 | 오프닝 | 물 공급, 환풍, "위층 창고까지 재료 나르기 힘들다" | 증기, 차양, 손님 줄, 고춧가루 자루 |

### 10.4 비노동 ~20%와 정책 결과 — 구성 의존 규칙
Jin 원안: "완전 잔인하고 악마적인 도시가 될 수도 있고, 누군가는 일을 안 해도 생존할 수 있는 도시가 될 수도 있다. 그 사람들이 주변에 좋은 영향을 미친다." 결과는 **도시 구성**에 따라 달라져야 한다 (도덕 퀴즈 아님).

| 정책 | 농업·가족 위주 성채 | 제조·노동자 성채 | 오락 성채 | 음성 성채 |
|---|---|---|---|---|
| **추방** | 가족 이탈 크게 (가구 `[플레이스홀더]` 40%), 할매 떠나며 텃밭 레이어 소멸, 위신↓↓ | 이탈 소량 (단신 노동자 많음), 수입 영향 거의 없음, 위신↓ | 이탈 소량, 방문객 소문 → 외부위협 소폭↑ | 거의 무반응. 팀장: "잘하셨습니다". 외부위협↑ (소문이 외부로) |
| **공동부조** | 할매·아이들 → 옥상 녹지 레이어↑, 위신↑↑, 식량 소량 | 재해 가구 복귀율↑ (산재 후 재취업), 비용 체감 큼 | 위신↑ → 상위 방문객↑ → 오락 수입↑ (돌봄이 간접 수익) | 비용만 나가고 위신 효과 상쇄. 조직원 가구는 부조 안 받음 |

## 12. 위신 시스템

그밸 "와인 브랜드 점수"에서 차용 `[확정]`: 장식·공용공간↑, 생산시설↓ → 유입 인구 질과 거래가에 영향.

### 12.1 계산 `[플레이스홀더]`
```
위신 = Σ(공용공간 셀 × 2) + Σ(장식 레이어 수 × 0.5) + Σ(네온경관 셀 × 1, 밤에만)
     − Σ(제조 셀 × 0.5) − Σ(음성 셀 × 2) − (문 밖 대기 인구 × 0.5) − (부패 중 말풍선 × 0.3)
     + 정책 보정 (7장 각 표)
```
- 범위는 골격 `economy.prestige.{min:-50, max:100}` 따름. 단계 `[플레이스홀더]`: 악명(−50~−1) / 폐허(0~19) / 판자촌(20~39) / 성채(40~59) / 명소(60~79) / 전설(80~100). 음수 구간이 있으니 미정 #6의 "악명" 축을 별도로 안 둬도 표현 가능 → 미정 #6 선택지 1이 사실상 골격 기본값.
- 골격은 `price_mult_per_10 = 0.05`, `inflow_quality_per_10 = 0.1` — 위신 10당 거래가 +5%, 유입 질 +10%. 아래 단계 표는 이걸 구간으로 묶은 것.

### 12.2 효과
| 위신 단계 | 유입 인구 질 | 거래가 (수입 배율) | 기타 |
|---|---|---|---|
| 악명(음수) | 조직원, 외부 고액 방문객 | ×0.75 | 음성 수입에 별도 배율 (미정 #6) |
| 폐허 | 떠돌이, 불안정 노동력만 | ×0.9 | 음성 산업 유입 가중↑ |
| 판자촌 | 노동자, 농사꾼 | ×1.0 | — |
| 성채 | 기술자, 가족 가구 | ×1.1 | 고양이 등장 |
| 명소 | 외부 방문객(오락 수입↑), 창작자 | ×1.25 | 외부위협 소폭↑ (눈에 띔) |
| 전설 | 상위 사업자 | ×1.4 | 후반 해금 조건 (생체건축 등, 17장) |

### 12.3 긴장 설계
- 미관 vs 생산 긴장 (그밸 그대로): 생산 셀을 늘리면 위신↓ → 거래가↓. 어느 지점에서 공용공간을 끼워 넣어야 한다.
- 음성 성채는 위신이 낮아도 수입이 높다 → 위신 무시 전략이 성립해야 한다. 다만 거래가 ×0.8은 음성 수입에도 적용되므로, 음성 성채도 **네온경관으로 위신을 억지로 올리는** 라스베이거스 전략이 나옴. 이게 의도.
- `[Claude 제안]` 위신과 별도로 **악명** 축을 둘지는 미정 #6. 단일 위신이면 "유명한 범죄 도시"가 표현이 안 됨.

## 18. 미정 사항 (우선순위 순)

번호로 골라줘. 복수 선택 가능하면 표시. 고르면 2장 표와 DECISIONS.md에 반영.

**#1. 가려진 내부 선택 UX** (5.3절) — 프로토 첫 주에 필요
1. 층 슬라이더
2. 탭하면 앞쪽 반투명
3. 단면 전환 버튼 (외관/X단면/Y단면)
4. 징수는 하단 큐로 분리 + 뷰는 2 또는 3
→ Claude 추천: 3+4

**#2. 도시 하루 길이 (실제 시간)** (15.1절) — 골격 `config.time.seconds_per_game_day=600` (10분)으로 들어가 있음
1. 4분 (5분 세션에 저녁 반드시 봄)
2. 6분 (GDD 초안)
3. 10분 (골격 현재값, 여유 있는 관찰)
4. 접속 때마다 하루 시작 → 저녁까지 고정 5분, 그 뒤 밤 무한 (세션 = 하루)

**#3. 오프닝 첫 경제활동 3지선다 구성** (4.3절)
1. 텃밭 / 고물 작업대 / 노점·마작판 (음성은 조건 해금) — 현재 초안
2. 텃밭 / 고물 작업대 / 노점 / **뒷골목 사무실**(음성 즉시) — 4지선다
3. 농업 / 제조 / 오락 / 음성 4축을 그대로 4장
4. 선택 없이 텃밭+작업대 둘 다 자동, 오락·음성은 전부 해금

**#4. 호칭 단어** (3.2절) — 성향별 1개씩. 골격 현재값: 따거(음성)·회장(제조, 인구60+)·촌장(농업), 오락 없음
- 농업: 1. 촌장 2. 어르신 3. 이장
- 제조: 1. 반장 2. 공장장 3. 회장(골격 현재값)
- 오락: 1. 회장님 2. 사장님 3. 오빠(풍자)
- 음성: 1. 따거 2. 큰형님 3. 회장님(오락과 겹침, 의도적)
- 공동부조 강할 때 접두 "우리" 붙일지: 1. 붙임 2. 안 붙임

**#5. 산업 허가 단계** (7.1절) — 골격 `industry_permit.multi_select=true` = on/off 2단계로 구현돼 있음
1. 금지/허가 2단계 (골격 현재값)
2. 금지/허가/장려 3단계 — GDD 초안
3. 허가 + 세율 슬라이더 (산업별 0~30%)

**#6. 위신 vs 악명** (12.3절) — 골격은 위신 −50~100 단일 축
1. 위신 단일 축, 음수 구간 = 악명 (골격 현재값)
2. 위신 + 악명 2축 (악명은 음성·오락 수입 배율, 외부위협 증가)
3. 위신 단일인데 음성 성채는 "네온경관"으로 메꾸는 라스베이거스 전략만 허용

**#7. 보존 토글 범위** (8.4절)
