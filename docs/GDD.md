## 0. 한 문장

제한된 12×12 사각 부지에 주거와 산업, 공급시설을 직접 배치하고, 다섯 계층 주민의 수요와 노동력을 관리하며, 탐험에서 가져온 자재로 자기만의 입체 성채를 완성하는 모바일 도시경제 게임.

핵심 순환: **주거 지정 → 입주 → 노동력 → 시장·작업장·물 → 수요 충족 → (자재를 골라) 승급 → 세수·노동력 변화 → 새 시설·상품·탐험 해금 → 공간과 공급망 재설계.**
바깥 순환: **부족한 자재 확인 → 지도에서 목적지 → 탐험대 파견 → 실제 시간 경과 → 수령 → 목재/철제/콘크리트 중 골라 승급 → 성채의 얼굴이 달라짐.**

| 경제 시계 | 경제일(日). 접속 중 1경제일 = 실제 10분 [확정: 하루 10분] | 생산·소비·세수·계약·연구. 배속의 영향을 받음 |

- 미접속 [확정: 느리게 + 보호]: 경제 시계가 **0.25배속**으로 흐르고 **최대 실제 8시간**까지만 계산 [실험값]. 미접속 중에는 주민이 떠나지 않고(유예 시계 정지), 재고가 0이 되면 그 소비·생산만 멈춘다. 돌아오면 요약(생산·소비·계약 이행·부족 시점·탐험 완료).
- 계약은 경제 시계를 따른다(소비와 같은 속도로 흘러야 재고가 어긋나지 않는다) [제안 — 브리프는 실제 시간을 권했으나 보류 사항이라 이렇게 정함].

### 1.1 실제 시간으로 얼마나 걸리나 [디렉터 기본안 — 브리프의 보류 항목, 시뮬레이션으로 정함]

- 경제 시계는 빠르다: 하루 4번 접속(합계 2시간 20분)이면 실제 하루에 **약 45경제일**, 하루 2번 10분씩이면 **약 26경제일**이 흐른다(접속 중 10분 = 1일, 미접속 0.25배·8시간 상한). 경제 시계에 묶인 것 — 세수·생산·계약·연구 — 만으로는 하루 이틀이면 끝까지 간다.
- 그래서 **"며칠짜리 게임인가"는 실제 시계로 도는 탐험이 정한다**: 승급 자재량(4 / 30 / 40 / 80)과 설비 부품(거물 승급 3개, 원거리 탐험이 주 공급원)이 관문이다. 건재상은 비싼 보조.
- 첫 접속은 빠르게: 시작 재고(세 자재 12씩)로 세입자 아홉 채, 근거리 탐험 몇 번이면 첫 토박이.

|---|---|---|
| 첫 세입자 | 7분 | 7분(첫 접속) |
| 첫 토박이 | 24분 | 12시간(두 번째 접속) |
| 첫 유지 | 15시간 | 2.5일 |
| 첫 거물 | 1일 | 3.5일 |
| 성채 회관 | 2일 | 6일 |
| 마지막 목표(거물 150 + 회관) | **6일** | **12.5일** |
| 10층을 다 채움 | 10일째 7층 | 21일째 7층 |

근거: `simulation/reports/SUMMARY.md`(튜닝 3), 이전 단계는 `round1/`(튜닝 1: 마지막 목표 1일 / 3.5일), `round2/`. 바꾼 수치와 이유는 `docs/BALANCE_CHANGELOG.md`.

## 2. 공간 [확정 + 제안]

- 부지 12×12, 최대 10층 [확정]. 칸 좌표 (x, y, z), z=0이 지상.
- 주거는 **1칸 = 1주거 단위**. 주거 지정은 칸을 칠하는 것이고, 칠한 칸에 판잣집(T1)이 바로 선다 [제안].
- 시설은 1×1 또는 2×2 [제안]. 플레이어가 층과 자리를 직접 고른다 [확정].
- **층 해금** [확정 80%]: z층의 "쓰이는 칸"이 144칸의 80%(=116칸) 이상이면 z+1층이 영구히 열린다. 쓰이는 칸 = 주민이 1명 이상 사는 주거, 완공된 시설 [제안]. 빈 판잣집·공사 중·지지대는 세지 않는다(공짜 칠하기로 층을 여는 것을 막는다).
- **지지대** [확정]: 열린 층이면 아래가 비어 있어도 지을 수 있다. 빈 아래 칸들에 골조가 즉시 생긴다. 골조는 방과 별개의 구조 상태(`supports`)이고, 나중에 그 칸에 건물을 지어도 된다. 비용 없음 [실험값].
- 아래 건물을 철거해도 위는 남는다. 철거한 칸에 위쪽이 있으면 골조가 남는다 [확정].
- 계단·복도·다리는 뷰가 자동으로 그린다. 서비스 접근은 거리로만 계산 [확정].
- 거리 [실험값]: `|dx| + |dy| + 2×|dz|`, 층 차이는 최대 2. 2×2 시설은 네 칸 중 가장 가까운 칸 기준.

### 3.1 수요의 세 역할 [제안]
- **기본**: 충족된 만큼 주민이 찬다(각 기본 수요가 정원의 일부를 맡는다). 전부 충족 = 만실.
- **승급**: 다음 계층으로 올리려면 전부 충족해야 한다. 충족 시 세수 +10%씩.
- **여유**: 선택. 행복과 세수(+15%씩)를 올린다.
- 대체 가능한 수요는 묶음이다(예: 끼니 = 채소·국수·어묵 중 아무거나). 주거는 한 번 고른 품목을 재고가 떨어질 때까지 유지한다(매 틱 바꾸지 않음).
- 상품 수요는 **재고 + 그 등급을 취급하는 시장의 범위** 둘 다 필요 [확정]. 서비스 수요는 가동 중인 해당 시설의 범위. 물·전기는 도시 전체 공급/수요 비율.
- 부족하면 유예(3경제일) 뒤 주민이 조금씩 떠난다. 회복하면 다시 찬다. 건물과 계층은 그대로 [확정].

### 3.3 입주·승급·이주
- 입주: 기본 수요 충족분까지 주민이 서서히 찬다. 도시 행복이 높으면 빨라진다.
- 승급은 **수동** [확정]: 만실 + 승급 조건 충족이면 표시가 뜨고, 플레이어가 돈과 자재를 내고 승인한다.
- 자재 [확정]: 승급마다 목재·철제·콘크리트 중 **하나**를 고른다. 세 자재의 요구 수량은 같다. 고른 자재가 그 주거의 외관이 된다. 떠돌이 판잣집은 공통 외관.

| 승급 | 돈 | 자재(셋 중 하나) | 추가 |
|---|---:|---:|---|
| 떠돌이→세입자 | 40 | 4 | |
| 세입자→토박이 | 150 | 30 | |
| 토박이→유지 | 1,000 | 40 | |
| 유지→거물 | 3,000 | 80 | 설비 부품 3 |

(튜닝 3 기준. 2→3부터 가파르게 오르는 까닭은 §1.1 — 자재가 실제 시간의 관문이다.)

- 승급하면 살던 주민은 새 계층이 된다. 정원이 느는 승급(4→8→12)은 빈자리가 나중에 찬다.
- **정원이 주는 승급**(12→8→6) [제안]: 넘치는 주민은 같은 계층의 빈집으로 자동 이주. 빈집이 없으면 "대기 주민"이 되어 3경제일 동안 노동력으로 남아 빈집을 기다리고, 끝내 없으면 떠난다. 확인 창이 "4명이 이주해야 함 / 빈자리 n"을 미리 보여준다. 인구는 조용히 사라지지 않는다.
- 여러 주거를 한 번에 승급할 수 있다(합산 미리보기).

노동력이 모자라면 우선순위 순으로 채운다: 물·전기 → 시장·서비스 → 식품 → 생활품 → 그 밖 → 음성. 같은 순위 안에서는 비율로 나눈다. 시장·서비스는 인력 50% 이상일 때만 가동(깜빡임 방지: 켜질 땐 60%).
생산 = 기본량 × min(인력 비율, 원료 비율, 물·전기 비율). 부족을 여러 번 곱하지 않는다.
저장 한도: 소비재·원료 60 + 창고당 120, 건축자재 200 + 창고당 200. 가득 차면 생산이 멈춘다.

## 5. 물·전기 [확정 구조 / 실험값]

수요 = Σ(계층 인구 × 1인 수요) + Σ(가동 시설 수요). 공급 = Σ(자체 설비) + 외부 연결. 비율이 1 미만이면 주거(기본 수요)부터, 그다음 시설 우선순위 순으로 배분.
외부 연결은 칸당 공급은 좋고 단위 비용은 나쁜 중간 선택지 [확정]:

| 전기 | 칸당 공급 | 공급 1당 유지비/일 |
|---|---:|---:|
| 소형 발전기 | 40 | 0.63 |
| 외부 전력 | 150 | 0.93 |
| 발전소 | 75 | 0.40 |
| 열병합 | 200 | 0.25 |

전기가 "필수"인 시설은 비율만큼만 돈다. 전기는 토박이의 기본 수요라서 세 번째 계층으로 가는 문이다 [확정: 전기는 발전 단계].

## 6. 돈 [제안]

- 세금은 자동으로 금고에 들어온다 [확정]. 세수 = 주민 × 계층 세율 × (1 + 승급·여유 보너스) × 행복 배수(0.85~1.15).
- 유지비는 계속 빠진다. 돈이 0이면 우선순위가 낮은 시설부터 멈춘다(금고는 음수가 되지 않는다).
- 장부는 다섯 줄로 나눠 적는다: 세수 / 유지비 / 교역(수입·수출) / 건설·승급 / 음성 수입. 주민에게 판 것은 세수에 이미 들어 있으므로 따로 매출로 잡지 않는다(이중 수입 금지).

## 7. 교역 [확정: 정기 계약 중심]

- 교역소 하나가 계약 슬롯 2개. 계약 = 상대 · 상품 · 수입/수출 · 회당 수량 · 주기(6/12/24경제시간) · 단가.
- 이행은 원자적: 수입은 돈이 있어야, 수출은 "최소 보유량" 위의 재고가 있어야. 모자라면 그 회차를 건너뛰고 이유를 남긴다. 벌금 없음.
- 거래처: 길 건너 도매상(처음부터: 원료 팔고 소비재 삼) · 건재상(세 자재를 비싸게 소량 [확정] — 하루 1~3개 ₩30~44, 설비 부품은 4~5경제일에 1개 ₩500~700) · 부두 암시장(전자 부품·양주, 탐험으로 발견) · 본토 보따리상(원단 싸게, 짝퉁·폭죽 비싸게 삼, 탐험으로 발견).

## 8. 탐험 [확정: 근거리 5~10분 / 원거리 수시간 / 전용 팀]

- 탐험 거점을 지으면 탐험대 1팀. 거점을 더 지어 최대 3팀 [실험값]. 주민 노동력과 분리 [확정].
- 지도: 성채가 가운데, 주변에 목적지. 각 목적지는 주력 자재 **보장량** + 덤(고물, 드물게 설비 부품·발견).
- 보급(선택): 끼니 10을 실어 보내면 수확 +25%.
- 결과는 사라지지 않고 수령을 기다린다. 늦게 받아도 손해 없음. 수령은 한 번만.

| 목적지 | 거리 | 실제 시간 | 보장 | 덤 |

| 철거된 가구 골목 | 근 | 5분 | 목재 5 | 고물 2~5 |

## 10. 행복·정책·연구 [Jin: 기존 결재·위신·악명 대신 Anno식 정책/연구/행복으로]

- **행복** 0~100: 주거마다 계산(기본 50 + 여유 수요 + 근처 정원·명소 − 옆 칸 공장 소음 ± 정책), 도시 평균을 보여준다. 세수 배수와 입주 속도에 영향. 필수품을 대신하지 않는다.
- **정책**(칸 수만큼 켬) [실험값]: 배급제(끼니 −20%, 행복 −8) · 초과 근무(생산 +20%, 행복 −10) · 감세(세수 −20%, 행복 +8) · 중과세(세수 +25%, 행복 −12) · 뒷돈(단속 위험 증가 −70%, 음성 시설당 유지비) · 입주 장려(입주 2배, 유지비).
- **연구**(공부방 필요, 한 번에 하나, 돈 + 경제 시간) [실험값]: 살림(공동 배급 → 방음 → 옥상 녹화 → 고층 급수) / 일(작업 정리 → 야간 교대 → 폐열 회수 → 정밀 공정) / 길(손수레 → 지도 제작 → 화물차 → 단골 거래).
- Anno 1800 본편에는 정책·연구 트리가 없다(정책은 DLC, 연구도 DLC). Jin의 요청으로 넣는 **우리 쪽 추가**다.

## 11. 음성 산업 [확정: 직설 풍자 유지]

하우스·콜센터·카지노·화약 가공소·무면허 치과·짝퉁 공방. 높은 수입, 대가는 **단속 위험**(0~100): 음성 시설이 올리고 시간이 내린다. 50에서 예고, 80에서 단속(음성 시설 하나 2일 폐쇄 + 벌금). 플레이어의 권한을 빼앗지는 않는다.

## 12. 화면과 조작 [제안]

기본 화면은 성채. 아래 다섯 버튼: **짓기 · 경제 · 탐험 · 교역 · 성채**(목표·정책·연구·기록).
1. 주거를 누르면: 계층·주민/정원·행복·세수·수요(충족/부족과 **원인** — 재고 없음/시장 범위 밖/취급 등급 부족/인력 부족/물·전기 부족) → 원인에서 해당 화면으로 바로 이동.
2. 승급: 세 자재 카드(보유량·외관 미리보기) → 정원·이주·노동력·수요 변화 → 결제.
3. 짓기: 층을 고르면 그 층 평면이 열리고, 범위·지지대·비용을 미리 보여준 뒤 확정.
4. 경제: 상품별 생산/소비/재고/소진 예상, 계층별 남는 노동력, 물·전기, 장부.
5. 탐험: 지도 → 목적지 카드(주력 자재·시간·덤) → 파견 → 남은 시간 → 수령.
6. 교역: 진행 중 계약(다음 배송·최근 결과) + 제안 목록.

## 13. 뷰 [유지]

3D 직교 씬을 저해상도로 렌더링하는 픽셀풍. 4방향 회전·줌·층 열기. 주거 외관 = 계층 × 자재 × 위치 × 전기 × 고정 씨앗. 골조와 빈 곳이 보여야 한다(꽉 찬 상자 방지). 그래픽 전면 개선은 게임성 뒤 [Jin].

## 14. 이 버전에서 안 하는 것
