## 3. 내가 정한 것(번호, 이유)
I1. V4Shim 삭제 — 질의·검증·뷰 호출은 진짜만. 없는 뷰 메서드는 조용히 fallback.
I2. **창이 떠 있는 동안 뷰 입력 끔 + 창 밖(도시) 클릭 = 창 모두 닫기**, 짓기 시작·도시로 가는 jump(focus/lens/inspect/build)는 창을 닫는다 — 계약대로 키가 창 뒤 카메라를 움직이지 않게 하면서 갇힌 느낌을 없애려고(Anno 식).
I3. **소식 카드는 창이 떠 있는 동안 숨기고 시간을 멈춤**, 토스트 줄은 오른쪽으로 — 목표 카드가 승급 창 자재 카드를 덮어 누름을 먹었다.
I4. **직접 줍기 = `ui/pc/RunPanel.gd` 하나**: can 이유 먼저 → `RunSandbox.tscn` 을 CanvasLayer 2 에(줍기 HUD 5·메뉴 6 아래) → 도시 UI·뷰를 숨김(소프트 GL 비용도 줄임) → Game ×1·멈춤 해제(끝나면 되돌림) → `Sfx.duck_city`. 결과는 CityLink 가 보낸 것을 확인만 하고, 거절되면 던전 재고·배낭 한도로 줄여 다시 보낸다(팀이 묶이지 않게 — 그 경우 카드에 "n개는 두고 왔다").
I5. 물건 id 표는 RunPanel.RUN_IDS(canned→cans, elec/ewaste→elec_scrap) 하나, Game.cmd 통과 지점에서 적용 — exp4 가 CityLink 를 고치는 중이라 그 파일을 건드리지 않았다(병합 충돌 방지). 목적지는 도시 id 를 그대로(줍기는 dest 를 지나가게만 한다).
I6. 줍기 쪽이 명령줄 인자(`script=`·`speed=`)를 읽어 하네스 실행에서 대본·배속으로 돌던 것을 열자마자 되돌린다(`run_auto=<성격>` 이면 자동 플레이).
I7. "한 판 더"(R) 로 새 판이 열리면 run_begin 을 다시 부른다(안 그러면 결과가 no_run 으로 버려진다).
I8. 분류 키 K·L(기반·명소) — v4 분류 11개에 아래 줄 9개뿐이라 줍줍 본부에 키가 없었다.
I9. 목표 100% 뒤 판정(2경제시간)까지 "곧 달성". 목표 보상(열리는 시설 목록)은 두 줄까지, 전부는 툴팁. 가는 버튼 넷까지·줄바꿈.
I10. 현황판: 꺼진 위험 행 "—"(100/100 막대가 '문제없음'처럼 보였다), 재고 칸, 이름 칸 190.
I11. 디버그 '층 채우기'는 다음 층이 열릴 만큼만(80%+6칸) — 시설 자리를 남긴다. 불·병 내기 = 고른 건물, 없으면 시뮬이 고른 집. '불·병 켜기(유예 없이)' 추가.
I12. 소리: 설정 막대 넷(전체·효과음·도시 소리·음악)+끄기 넷, 창 안 탭·분류 탭 = tab, 짓기 카드 호버 = hover. 사건 소리는 AudioDirector 자동 그대로(UI 와 겹치는 것 없음).
I13. 위 띠: 실제로 넘치면 압축 단계를 하나 더(후반 큰 숫자에서 배속 버튼이 밀려났다).
I14. 오프닝 금테는 창이 떠 있으면 숨김. 사라진 카드 위에 남던 툴팁 없앰.

## 4. SIM에 넘길 것
1. **배낭 한도**(위 1): 40 → 80 으로 올려 두었다. 줍기 쪽 실제 분포(RUN_NOTES §8)에 맞춰 다시 정할 것. 두목 큰 짐(설비 부품 3·전자 폐품 4)이 던전 재고에 없으면 줍기는 그만큼 줄여 주지만, 도시 쪽 `run.boss` 덤과 이중 보상인지 확인.
2. **쓰러짐 이중 손해**: 줍기가 `down` 이면 이미 묶음 절반을 버리고 보내는데(RunWorld `_finish`), `run_result` 도 `down` 이면 다시 절반 — 한쪽만.
3. **finds 형식**: 줍기는 "도면: 압축기 큰형의 설계도" 같은 문장을 보내고 시뮬은 "type:id" 만 받는다 → 조용히 버려진다.
4. **해금·목표 판정 2경제시간 지연**: 3층 카드·병 안내 카드가 "넝마주이 조합을 지어라"라고 말한 뒤 ×1 로 최대 50초 동안 그 카드가 잠겨 있다(재현: 2층 채우기 → 3층 열림 직후 방재 분류). `floor_unlocked` 때 해금 판정을 바로 한 번 돌리면 된다. 목표 100% 뒤 카드도 같은 지연(UI 는 "곧 달성"으로 메움).
5. **물 첫 부족**: 판잣집 8채에 수도국 하나(20)로는 24명에서 막혀 첫 승급이 안 온다(만실이어야 해서). 첫 목표 문장(필수 셋)에 "물은 사람 수만큼"이 없다 — 수도국 1개 공급을 30으로 하거나 목표를 "수도국 2"로.
6. 데이터 이름: `trade_post`·`expedition_base` 를 v3 이름(교역소·탐험 거점)으로 부르던 UI 문구는 고쳤다. 
7. 병 수업에서 넝마주이 조합 범위가 "주거의 0%"로 남았다(공사 중이라 그런지 확인 못 함).

## 5. 줍기에 넘길 것
1. `run_goods.json` `city_id`: **canned → `cans`, elec → `elec_scrap`**(exp4 의 추정값 canned·ewaste 는 도시에 없다). 맞추면 RunPanel.RUN_IDS 는 하는 일이 없어진다.
2. 던전 id: 도시는 `junk_yard`(이름 고물 야적장). UI 는 도시 id 를 `run.dest` 로 넘긴다.
3. `standalone=false` 이면 명령줄 인자(`script`·`speed`·`auto`·`mute`)를 읽지 말 것.
4. 도시 모드에서 결과 화면 "한 판 더"는 run_begin 없이 새 판 — 숨기거나 도시에 물을 것(지금은 UI 가 대신 다시 부른다).
5. RunSfx 의 M(소리)은 주 버스(0)를 직접 끈다 → 도시 설정과 엉킨다. 자기 버스를 쓸 것(UI 는 닫을 때 버스를 다시 맞춘다).
6. 결과 `lost` 가 이미 절반 처리라 도시 쪽과 이중(SIM 2).
