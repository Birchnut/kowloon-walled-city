- 건축 개입: **정책만 정하고 자동 성장** (심시티식 구획 아님, 직접 증축 아님)
- 매 접속 행동: **상시 정책 패널 + 하루 끝 제안 카드 3장** + 그레이프밸리식 **주기적 수확(징수)·랜덤 성과**
- 그레이프밸리에서 v1에 가져올 것: (1) **타이머 징수 + 방치 시 부패**, (2) **성채 위신** (공용공간·장식↑, 생산시설↓ → 유입 인구 질·거래가에 영향)

- v1 정책 축 4개 모두 포함: **산업 허가**(농업/제조/오락/음성), **입주·돌봄**(누구나/노동우선/추방/공동부조), **세금·투자 우선순위**(증축/생활환경/설비), **자재·외관**(목재우선/철판/네온경관/외벽녹화)
