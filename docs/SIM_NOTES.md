## 1. 구조 한 장

- `sim/Sim.gd` — 규칙 없음. 시간을 정시 단위로 끊어 시스템을 순서대로 부르고, 명령·질의를 배달하고, RNG·데이터·지표 캐시를 든다.
- `sim/systems/<id>.gd` — 규칙 묶음 1개 = 파일 1개. 공통 모양은 `sim/SimSystem.gd`(전부 선택 구현):
  `on_new_game · tick · on_hour · on_day_end · on_day_start · fast_forward(요약 줄) · metrics · can/apply/query · on_command · describe(cell_info 줄)`.
- 시스템끼리는 서로를 안 부른다. `CityState`만 읽고 쓴다. 남에게 시킬 일은 `state.flags`의 요청 큐에 쌓는다(가게 들이기, 가구 보내기, 카드 예약…).
- `config.json`의 `systems`에서 id를 지우면 그 규칙이 없는 게임이 된다(시험 4번이 13개를 하나씩 꺼 본다).
- 도우미(순수 함수, 시스템 아님): `Expr`(JSON 조건·가중합·효과), `Metrics`(이름 붙은 숫자), `Grid`(공간·볕), `Placement`(자리 점수), `GrowthUpgrade`(자재·고쳐 짓기·쪽방), `Ops`(가구·사업체·셀 넣고 빼기), `Bot`, `SimIO`.
- JSON 식: 조건 `["population", ">=", 40]` / `{"all":[…]}` `{"any":[…]}` `{"not":…}`, 가중합 `[["jobs_open", 0.3, 상한]]`, 효과 `[["money","+",200], ["unlock","id"], ["spawn_business","loan_office"], ["queue_card","id",지연일], ["mission","id"], ["policy","axis","값"], ["transfer","alley_fund","money",0.5], ["if",조건,[…],[…]], ["chance",0.5,[…],[…]], …]`. 전체 목록은 `sim/Expr.gd`. 쓸 수 있는 지표 이름은 `sim/Metrics.gd` 주석과 `Game.query("metrics")`.

## 5. SIM 담당이 혼자 정한 것 (승인 필요 — 번호로 뒤집어 주세요)

디렉터 지시서에 없어서 내가 정한 것들이다. 전부 데이터나 파일 하나로 되돌릴 수 있다. **★ = 게임 감각에 크게 닿는 것(먼저 봐 주세요).**

규칙
1. ★ **비운 터(keep)는 이미 지어진 기둥에 못 칠한다**(먼저 철거). 이유: "비운 터에 셀 없음" 불변식을 글자 그대로 지키려고. 대안: 지어진 기둥에 칠하면 "더는 못 올림(보존)"으로 해석.
2. ★ **자재 강도(load)가 기둥 높이를 정한다**: 폐자재 위로 2층, 목재 3, 함석 4, 벽돌 6, 콘크리트 12. 약한 칸이 아래 깔리면 그 기둥은 멈추고, 주민이 "보강"해야 다시 오른다. 콘크리트는 전기가 있어야 쓴다. 이유: 자재 정책이 실루엣(높이)에 바로 보이게.
3. ★ **층 한도 = 4 + 물탱크 1개당 3층**. 이유: 지시서의 "물이 위층을 제한"을 한 줄 규칙으로.
4. ★ **하늘을 열어 둬야 하는 칸(텃밭, 옥상 농장, 비둘기장, 온실, 물탱크) 위에는 아무도 못 짓는다.** 이유: 볕 드는 마당·테라스·단차가 저절로 생기게. 부작용: 농업 성채는 금방 "꽉 찬다"(farmer 419칸).
5. **기둥마다 씨앗에서 나온 고정 성격값(column_bias)**이 있어 어떤 자리는 탑이 되고 어떤 자리는 낮게 남는다. 이유: 매 판정의 무작위는 평균돼 판판한 슬래브가 됐다.
6. ★ **수금 구역 = 앵커 중심의 수평 원(전 층 공통), 가장 가까운 앵커로.** 공공 시설(수도·사당 등)도 전부 수금함을 가진다.
7. ★ **수금 수치**: 수금함은 그 구역 하루 수입의 0.6일치에서 가득 찬다. 80%를 넘긴 채 4시간 → 시간당 5%가 뒷골목 금고로, 넘친 돈은 전액. 실제 시간으로는 접속 중 약 6분, 미접속 약 5시간이면 가득. 하루에 한 번 들르는 사람도 조금씩 떼인다.
8. ★ **금고가 비면 뒷골목 금고가 1.5배 값에 쌀을 산다**(악명↑). 지시서에 없던 규칙. 이유: D3 "벌 받지 않고 표류한다" — 이게 없으면 방임 도시는 그냥 굶어 무너졌다.
9. **윗선**: 음성 가게 3칸이면 접촉 카드. 받으면 거두는 돈의 2할 상납 + 호칭 강제('따거'), 이후 입주 정책 지시·상납 인상·"이러시면 안 됩니다" 카드. 결재로 들인 가게는 금지령에도 스스로 안 닫는다(철거·단속 카드로만).
10. **음성 제안 카드는 음성이 '금지'여도 올라온다**(유혹). 허가를 열면 카드 없이도 스스로 들어온다.
11. **쪽방 조건**: 집 없는 가구 5 이상이고 (카드로 허락 / 입주 = 일꾼 우선 / 악명 25 이상 + 음성 허가) 중 하나. 하루 2칸까지, 볕이 제일 안 드는 방부터.
12. **주거 정원**: 판잣집·단칸방 1가구, 살림집 2, 쪽방 4. **가구 1 = 일손 1.**

## 6. 알려진 약점 (숨기지 않고)

- **farmer가 419칸**으로 목표(500~900)에 조금 못 미친다. 원인은 결정 4(농장이 기둥을 묶음). 농업 성채의 성격이기도 해서 그대로 뒀다.
- **"위신도 악명도 높은 라스베이거스"는 아직 못 보여 줬다.** merchant는 악명 100·위신 0. 두 축은 분리돼 있고 네온·공공 시설로 위신을 올릴 길은 있지만, 그런 봇을 만들어 확인하지 않았다.
- **뒷골목 금고의 쓸 곳이 적다**(merchant 10,177이 쌓인 채). 쌀 풀기와 카드 몇 장뿐. 금고가 스스로 가게를 차리거나 집을 사들이는 규칙이 있으면 D3이 더 살 것.
- **후반에 돈이 남는다**(factory 8,481). 돈 쓸 곳이 앵커·식량·자재·카드뿐.
- **absent의 도시는 거의 안 자란다(62칸).** "미접속 중 자동 성장 없음"의 직접 결과. 의도한 모습인지 판단 필요 — 선택지: ① 그대로(접속이 곧 성장) ② 복귀 직후 밀린 공사를 빠르게 따라잡는 "몰아 짓기" ③ 미접속 중에도 아주 느리게.
- 카드 밸런스는 손대지 않았다. 봇은 태그 취향으로만 답하고 약속(mission)을 일부러 지키지 않아 약속 보상은 거의 검증되지 않았다(성공 1, 실패 16).
- 30일 헤드리스 실행이 봇당 37~53초(후반 하루 2~3초). 매시 전 셀을 훑는 곳이 셋(지표, 수금, 유입). 실시간(도시 1시간 = 25초)에는 문제없어 보이지만 저사양 웹에서는 재 봐야 한다.
- 뷰·UI와 붙여서 돌려 보지 않았다(헤드리스 + Game 오토로드 탐침만). `cell_info` 문장과 이벤트 순서는 실제 화면에서 확인 필요.
- 파일 길이: `collection.gd` 268줄, `Sim.gd` 361줄로 "250줄 안쪽" 기준을 조금 넘는다.
- `why`(왜 여기에)는 지을 때 한 번 적힌다. 나중에 이웃이 바뀌어도 문장은 그대로다.
